## 产品决策

用户本轮明确要求增强650–1000ms与1–5秒的变化，并让5秒后的持续动效看不出整段循环。R9.1的水珠拖尾被用户否定。R9.2重做撞击、飞溅与湿痕，沿用品牌与背景，保留同色系浅绿。用户提供雨窗照片为形态参考，不将其暗色蓝绿背景迁入产品。

这是请求等待期间的品牌动效。目标是让进入书房有一个明亮、自然、有记忆点的瞬间，不增加访问成本。约1秒是完整视觉节奏，不是最短驻留。关键数据和安全会话就绪即开始进入，动画可以在任何帧中断。

“炫酷”落实为细绿墨线的书写、山水显影、雾层让位和水光扩散；不使用重3D、霓虹、闪光爆炸、满屏粒子、假百分比、声音或仪式性文案。撞击的折光与微小溅珠形成局部变化，不是全屏闪白或高频闪烁。中央只有“此刻”，不拿用户状态或成长评价作开屏文案。

## 视觉分镜与尺寸

| 时间 | 动作 | 实现 |
|---|---|---|
| 0–220ms | 纸面生光，品牌起笔 | 内联SVG与纸白即时可用；柔光渐显；题名延迟90ms显影 |
| 220–650ms | 绿墨成形，竹梢展开，山水浮现 | 细圆弧stroke-dashoffset 420→0；竹干描线480→0，叶片渐显 |
| 650–1000ms | 青雨初落，局部闪亮 | 约640～710ms第一次撞击，间隔180～350ms第二次；4～7颗小水珠飞溅，140～280ms扩散，不用同心圆 |
| 1–2秒 | 新落点继续出现 | 雨量收紧，主要是透明圆珠停留，品牌安全区无滴 |
| 2–3秒 | 玻璃水珠滑动 | 只有少数水珠滑落65～130px；轨迹不规则，湿痕按实际已滑过的位置显露 |
| 3–5秒 | 窗光与细雨展开 | 青绿玻璃光带600–5000ms缓慢掠过；雨滴继续落下与淡去 |
| 5秒以后 | 独立、错相的持续机制 | 雨滴非整段重播；雾7.3/11.3秒、竹9.1秒、水纹5.7秒、露光3.7秒独立呼吸 |
| 任意时刻就绪 | 直接露出首页 | 整层140ms opacity 1→0，首页同步可交互；没有额外等到1秒的逻辑 |

动画缓动 cubic-bezier(.22,.7,.2,1)，退出 ease-out。桌面中央200×200、垂直中心44%；品牌45px宋体，墨绿#395C38。手机整体0.84倍、垂直中心43%；竹影靠右上，山水靠底。自然背景复用R8横/竖图，装饰无交互、aria-hidden。圆环是绿墨意象，不与请求进度绑定，不代表完成比例。

首页背景与开屏共用同一组图片、同一锚点；品牌和水纹溶解后，读到首页内容。无需额外视频、字体大包或3D运行时。当前原型纸白是即时首帧；背景图片若没解码，不等待它，而继续以SVG与纸面提供反馈。

## 状态与等待契约

OPENING → READY/ENTERING → HOME，或 OPENING → SLOW → FAILURE。每次启动持有独立generation/session标记；重试、退出、切换账户取消旧计时与旧动效，过期响应不参与进入。

- 快请求：已满足安全会话＋首页DOM＋关键数据则立即退出。若启动前就已ready，直接显示首页，不为展示品牌强制闪一次。
- 约1秒：常规900ms请求示例在就绪后进入140ms溶解；视觉完整态时长约1秒。
- 慢请求：1秒后有持续可见的雨滴与玻璃滑痕，5秒以后无清场/品牌重播，3.5秒轻提示“连接比平时慢，正在继续尝试”。不得把时间换算为假进度。
- 错误：请求明确失败立即显示恢复层；原型为了完整观看长等待，10秒只露出轻量“重新连接”，30秒模拟失败；这两个值是设计候选，不修改真实API超时。正式接入继续遵守现有请求策略，明确失败就停止并恢复；不能为播放雨景延长真实请求期限。播放器“持续雨景”不模拟真实请求，手动进入，因此不走30秒失败。
- 恢复：重试建立新generation，忽略旧响应；原型重试为900ms固定成功模拟。错误不通过空数据/假状态完成开屏。
- 未登录：身份确认后直接进入现有登录界面，不等待用户首页请求。进入深链时显示其安全目标页，不强迫改路由去首页。
- 热恢复：仅在确有关键等待且页面不可安全交互时出现；应用内路由、后台轮询、切栏目不重复全屏动画。恢复已可用页面不播整段。
- 离线：只有现有授权与数据策略确实允许使用当前账户本地数据时才进入离线可用页；本原型不伪造离线能力。

## 现有启动链与接入点

只读参照本地 `public/frontend/app/runtime.mjs`：bootstrap() 先 /api/auth/me 与 local-test-mode；activateUserSession() 调 load()、恢复会话草稿和待同步投影，再 revealUserSession()。load() 当前并发 state/settings/onboarding/schema/session/meta，render 后还等待行动数据。源码观察不保证此刻线上部署完全同版。

**第一步先沿用 revealUserSession() 的安全就绪点显示目标页面**，未登录/失败沿用现有auth gate。开屏不扩大权限，不取消现有会话归属校验，不展示上一账户缓存。若之后要缩短关键路径，应单独拆分首页必要数据与次要数据，并证明原有会话恢复、投影和错误处理仍成立；这不属于本轮设计实现。

不把所有请求、图片、小物媒体、通知、模型任务、折叠区数据都新增为屏障。只以真正能交互且安全的首屏就绪为准。背景资源不能阻塞身份或数据请求；图不出现时也必须退出到可用页面。

生产使用同一DOM壳中的覆盖层，**不使用原型iframe作为架构**。需向动效控制器提供 start()/ready()/fail()/dispose() 语义信号；控制器不自己发认证或业务请求。ready()幂等；取消在退出时清理WAAPI动画、CSS循环、计时器及监听。pagehide清理，恢复时重新读有效状态。减少动态效果直接静态展示并零时长退出，同时禁用雨滴与局部微光。

## R9.2：飞溅、水珠和玻璃湿痕

- 主要落点在横向9%～91%、纵向6%～25%；多数仅停留，避免给每颗水珠配尾巴。初次两颗之后的撞击间隔1.05～2.4秒，不连成均匀雨帘。
- 主珠透明、圆润，半径3.8～5.9px，用浅绿径向折光、局部高光及下缘暗部体现玻璃珠，拒绝实心绿色尖头形。滑落珠半径5.8～7.6px。尺寸为CSS像素，双端不放大成悬浮装饰球。
- 雨点击中后25ms以内显现；4～7颗半径0.6～1.4px的小溅珠沿随机方向扩散8～24px，140～280ms完成，多数消散，少数停留。不是池塘同心圆，也不是星光闪烁。
- 多数主珠停在原地1.9～4秒并淡去，没有湿痕；仅位于左右安全区域的少数珠子可能滑落（30%条件概率，乘边缘区域占比后总体约15%，另有并发限制）。同时最多一颗滑落珠，全部雨事件DOM上限5个。
- 滑落前停留650～1200ms；位移65～130px。路径由5段向下递增的随机横向偏移组成，不做周期摇摆。品牌中央不被滑落轨迹穿过。
- **水珠和湿痕是独立的图形。** 珠体沿随机轨迹移动；固定在原落点的SVG路径用dashoffset按路程逐步显露，仅绘制已经走过的部分。湿痕约1.15px、低透明度，两侧有很淡的折光；不将整条痕迹绑在珠体上平移，不预先画长尾，不让痕迹越过当前水珠。
- 每次打开/重播通过crypto.getRandomValues生成新种子；位置、时机、尺寸、溅珠方向、停留/滑落、轨迹都随之变化。可回退时间与随机数组合。不是固定240510种子的重复排列。
- 同一场雨内，逐帧取样保持该种子；可选URL参数seed仅供评审复现，不进入产品UI。当前截图取样seed=10546、3200ms，特意展示一个合法的少数滑落场景，不代表每次必定滑落。
- 连续事件用生成器只安排下一次落点，5秒没有全局重置或整页循环；雾、竹和水纹继续各自错相。生命周期结束回收DOM/动画，离开/就绪/重试清理；页面隐藏不生成新事件。
- 关键就绪随时140ms退出，不等水珠滑完。减少动态效果禁用雨点、飞溅与滑落。未新增3D、视频或外部素材。

## 无障碍与性能

等待期间目标内容inert，辅助技术只听到一次“正在打开此刻”；不朗读每帧或重复百分比。就绪解除inert；错误将焦点交给重试按钮。减少动态效果禁用描线、平移、缩放、雾动与水纹循环，保留静态品牌和纸面。没有音效。

代码内SVG、CSS和JS可就近内联，控制首次开屏新增压缩代码预算约10KB以内（预算，未测性能）；不要为动效引入库。现有R8 PNG约1.6MB/张，生产应随背景交付统一压缩、按设备加载一张并缓存；不为了开屏额外请求两张原图。opacity/transform为主，SVG描线范围小；避免逐帧JS绘画、大尺寸动态blur和持续高频粒子。资源失败降级纯纸白+SVG，旧浏览器不支持WAAPI时直接静态等待与即时进入。后续真实低端设备帧率与包体应在实施阶段确认，本轮不启动测试。
