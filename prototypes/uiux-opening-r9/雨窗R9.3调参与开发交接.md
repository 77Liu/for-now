# R9.3 · 连续雨窗与宽水膜

2026-10-05。范围：开屏视觉原型、持续动画与参数交付；不修改生产、不启动测试。本规格替代R9.2的雨滴实现与对应参数，其余首屏布局和API就绪语义沿用R9。

## 可以直接使用的交付

- `rain-lab.html`：持续播放的双端调参页。每次雨点随机；不会在5秒时重播整个场景。
- `rain-engine.js`：调参页与完整开屏共享的Canvas 2D引擎，无第三方依赖。
- `rain-presets-r9.3.json`：四组设计预设，包含单位和版本。
- `index.html`：完整开屏已使用同一宽水膜引擎，保留关键就绪即退出、错误重试和逐帧取样。
- `guide.html`：开屏评审入口，链接调参页。旧3200ms截图已标注历史，不用于判断当前水膜。
- 调参页可复制/下载JSON，携带当前配置、版本和样本编号；“带入完整开屏”把当前配置传入完整开屏持续模式。

## 水的形态与运动

1. 玻璃上的撞击在约24ms内显现，珠体在约160ms内完成轻微的展开与回收；小溅珠沿随机方向扩散，大部分消失，少数停留。
2. 停留珠没有尾巴。滑落珠先停留约0.28～1.23秒，再向下滑动；下坠有轻微停顿感与不同速度，不做周期左右摆动。
3. 拖尾为**闭合的透明水膜面**，由已走过的中心轨迹和两侧法线计算，宽度沿程变化。两侧有绿调暗缘、高光和局部水膜纹理；头部水珠明显厚于水膜。
4. 仅绘制已走过的轨迹；水膜留在玻璃原位。水珠继续下移时，之前的水膜不随之整条平移，也不提前长出整条尾巴。
5. 横向偏折为分段平滑的随机轨迹。滑落距离为画布高度的18%～46%，上限420 CSS px。路径偏折为0时保持直线。
6. 已滑落水珠接触停留主珠时，会吞并它、稍微变大，并留下局部较宽的水膜。用体积近似合并，半径上限24px；不是每一滴必有合并。
7. 滑落后珠头约0.8秒内淡出，原位水膜按保留时间独立淡去；停留珠在其寿命尾端约2秒淡去。无全局清场或倒带。

这是一套用于界面视觉的水珠运动/折光近似，使用渐变与轮廓表现水膜厚薄，没有引入流体求解器、背景像素折射或3D渲染。若评审目标升级为摄影级折射，再单独评估WebGL资源与低端机成本；当前无需Blender。

## 参数合同

所有尺寸采用CSS px；屏幕像素比只影响清晰度，不改变水珠视觉尺寸。

| 字段 | 含义 / 单位 | 可调范围 | 疏雨默认 |
| --- | --- | --- | --- |
| density | 目标撞击频率，滴/秒 | 0～10 | 1.6 |
| trailPercent | 主珠撞击后会滑落的概率，% | 0～100 | 38 |
| dropSize | 主珠基础半径，px | 2～14 | 6.5 |
| trailWidth | 水膜标称总宽，px | 2～22 | 8 |
| speed | 标称滑落速度，px/s | 15～180 | 72 |
| bend | 随机横向偏折强度，% | 0～100 | 38 |
| splash | 每次撞击的飞溅小珠数 | 0～10 | 5 |
| trailLife | 头部滑完后水膜淡出时长，秒 | 1～18 | 6 |
| beadLife | 停留主珠基础寿命，秒 | 2～25 | 9 |
| contrast | 水珠/水膜折光强度，% | 20～140 | 75 |
| protectBrand | 滑落路径避开品牌中心 | boolean | true |

真实主珠半径有约0.72～1.22倍随机变化；滑落珠半径至少为水膜标称宽度的0.68倍，避免水膜大于水珠。水膜宽度沿程随机变化约0.68～1.26倍，起点收窄，吞并处有局部增厚。寿命也有少量随机变化。

拖尾百分比在空间落点之前独立判定，品牌保护不再乘掉总体比例。0%全部停留、100%全部滑落；有限样本的实际比例可能偏离所设概率。保留品牌保护时，滑落珠重新分配到左右区域。不是“100%但仍只一颗滑落”的隐藏上限。

雨密度通过随机事件间隔实现，约为目标频率，非精确计数器。密度设为0后停止新增，现存珠子和水膜仍自然完成；恢复雨量不补发停止期间的雨滴。

## 调参UX

- 滑块和数字输入同步。有效数字可实时应用；越界值在提交时夹取到范围。
- 新参数只影响之后的撞击，已有珠子继续自己出生时的生命周期，避免突然跳变。首次调节不清空画布。
- 预设也只改变新雨点。“清空玻璃”才明确清场，并从同一随机种子重新开始。
- “换一场雨”更换种子并清场；“重播此样本”沿用当前配置与指定种子从头播放。
- “暂停雨景”冻结玻璃；恢复后从当前位置继续，暂停期间不补发雨点。
- 切换手机/桌面会重新生成当前种子的雨，避免旧坐标超出新画布。手机原型画布最大390×844；窄屏调参页上下排布，画面保持可见、参数可向下访问。
- “展示品牌”仅控制评审品牌显示；它不自动取消品牌安全区，需要单独关掉保护选项。
- 配置存入本地localStorage；不可用时继续运行，仍可以导出JSON。
- 复制失败明确给出下载替代；导出带版本、样本编号、配置，前端可以直接引用。

## 引擎接口与接入

```js
const rain = new GlassRain(canvas, config, seed);
rain.start();           // 连续运行
rain.update(nextConfig);// 新雨点用新参数
rain.pause();           // 暂停；再次start恢复
rain.reset(seed);       // 清场并沿用/替换随机种子
rain.seek(5000);        // 固定60Hz模拟到指定毫秒，停在该帧供评审
rain.dispose();         // 释放rAF、ResizeObserver、visibility监听
```

`GlassRain.validate()`统一夹取参数，`GlassRain.defaults`为疏雨默认；`GlassRain.freshSeed()`生成样本。复制JSON的`config`可直接作为构造参数。同样的配置、种子、画布尺寸，沿用固定模拟步长可复现落点与路径；若中途改参数、合并或切换尺寸，则应从头复现。

调参页主动播放是评审操作。正式开屏遵循减少动态效果设置，禁用雨；首屏关键就绪随时140ms收束，不等雨滑完。失败暂停雨，重试清理再开始；退出和pagehide必须dispose。开屏依然沿用现有安全会话就绪语义，原型iframe不进入生产架构。

性能边界：Canvas最大DPR=2；活动主雨事件上限160，每条轨迹约250点以内；已有飞溅仅在初期绘制。requestAnimationFrame驱动、固定60Hz模拟；隐藏页面停止推进，不积压补发。雨量与寿命同时拉满可能触及上限，实际新增量会下降。当前原型是持续调参用的上限，正式默认宜保留疏雨量级。没有宣称真实低端设备帧率或包体达标，生产性能验证留给批准后的开发阶段。

## 人工观察

人工打开实际运行页，查看了水痕特写中的宽水膜、持续15秒以上的雨景，以及数字输入与滑块的同步；这些是视觉原型的人工查看，不是自动化测试或生产验收。未启动测试、构建、部署，也没有调用线上API。调参页及完整开屏共用引擎，避免定稿后出现两套雨。
