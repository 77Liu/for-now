# 开屏雨景 · 主账户设置 PRD / R9.4

2026-10-05。用户新增明确需求：允许主账户在设置中调整动画配置。本轮交付产品规格与可操作原型，进入后续V0.5.x计划；尚未接入生产账户、接口或配置存储，没有启动测试。

## 产品目标与边界

“此刻”开屏是一小段有自然气息的等待，页面真正就绪时马上进入。让主账户能调出喜欢的雨势，而不是强迫每次观看一段固定片头。

入口：我的 → 设置 → 开屏与氛围。主账户可编辑并保存，普通账户本期不展示该编辑入口；已有默认开屏不受影响。**当前按账户个人偏好定义**，主账户的调整只影响自己的设备/账户体验，不自动修改所有人的默认样式。不把主应用的主账户与平台中台owner角色混为一谈。

本期包括：开屏动画开关、12个雨景参数、品牌保护、实时持续预览、显式保存、取消、恢复默认、保存失败保留草稿。背景/字体/首页布局仍沿用已批准方案；不扩展成主题商店。

## 页面与交互

`rain-settings.html`为产品设置原型：

- 默认展开“开屏动画”“雨水密度”“产生拖尾”。“更多雨景参数”按需展开大小、宽度、速度、起滑延迟、距离、偏折、飞溅、保留时长和折光。
- 大面积即时预览保留浅绿山水与品牌；参数区域清楚但不做多层卡片。电脑左右排，手机上方预览、下方参数，保存操作保留在可达的位置。
- 预览持续运行，用户可暂停与换随机样本。参数变化影响新的雨点，已经存在的雨自然结束。
- 参数修改先进入草稿；“保存设置”才持久化。保存前不影响下次真实打开；取消还原上次成功保存的值。
- 恢复默认只修改草稿，不直接覆盖已保存配置；仍需保存。
- 开屏动画关闭后预览立即转为静态山水与品牌，数值变灰但保留；下次打开也使用静态等待，不虚构加载完成。
- “试看已保存的开屏”进入完整原型，使用成功保存的配置。演示900ms关键请求返回后进入R8首页。未保存草稿仅在当前预览中显示。
- 离开有未保存更改时，可继续调整、放弃修改、保存并返回；保存失败留在编辑页，保留草稿与重试能力。
- 系统减少动态效果始终优先于实际开屏的动画开关；设置页的主动“播放预览”仅用于评审自己的效果，不改变系统偏好。

原型顶部账户视角/演示失败控件是评审工具，**不进入产品页面**。主账户/普通账户切换仅演示入口显隐；不是实际权限校验。原型保存仅本机localStorage，已明确标注。

## 状态定义

| 状态 | 页面行为 |
| --- | --- |
| 初次进入 / 无已保存配置 | 使用R9.4默认参数，保存与取消禁用 |
| 有更改 | 显示“有未保存的调整”，允许保存/取消；预览即时变更 |
| 保存中 | 不接受重复提交与配置修改，保留当前预览，不关闭页面 |
| 保存成功 | 更新当前有效配置及修订号；未保存标记消失 |
| 保存失败 | 明确提示“调整仍保留，可以重试”，草稿和预览不丢失 |
| 关闭动画 | 静态预览；保留原参数，重新开启可继续用 |
| 恢复默认 | 草稿变为默认，保存后生效 |
| 取消 / 放弃 | 恢复最后保存值，或返回设置列表 |
| 权限失效 | 停止写入；真实产品依据服务端能力调整入口，草稿不写给其他账户 |
| 已保存配置不支持当前版本 | 迁移已知字段，缺失项补默认；读取未知版本失败则安全使用静态/默认开屏 |

## 定稿参数与默认

| 配置字段 | 范围 / 单位 | 默认 | 产品标签 |
| --- | --- | --- | --- |
| enabled | boolean | true | 开屏动画 |
| density | 0～10 滴/s | 3.5 | 雨水密度 |
| trailPercent | 0～100 % | 60 | 产生拖尾 |
| dropSize | 2～14 px半径 | 7.5 | 水珠大小 |
| trailWidth | 2～22 px标称宽 | 12 | 湿痕宽度 |
| speed | 15～180 px/s | 85 | 滑落速度 |
| slideDelay | 0～250 ms | 50 | 撞击后起滑 |
| slideLength | 60～400 px | 145 | 滑落距离 |
| bend | 0～100 % | 80 | 路径偏折 |
| splash | 0～10 颗 | 5 | 飞溅小珠 |
| trailLife | 1～18 s | 4 | 湿痕保留 |
| beadLife | 2～25 s | 9 | 停留珠寿命 |
| contrast | 20～140 % | 119 | 折光强度 |
| protectBrand | boolean | false | 避开品牌中央 |

拖尾比例是事件概率，不是短时屏幕占比；0%全部停留、100%全部滑落。密度0停止新增，已有水自然结束。大小、宽度、距离与保留时间有适度随机变化，尺寸全为CSS px。起滑延迟真实随机为所设值的0.7～1.3倍；默认35～65ms，0即不故意等待。具体材质与轨迹见R9.4动效交接。

## 数据与接口建议（待开发，当前不存在）

只读查看了本地源码：现有 `/api/settings` 为AI/语音配置的GET/POST，不应把雨景参数直接塞进模型设置表单。建议独立账户外观偏好模块：

- `GET /api/ui-preferences`：返回当前账户的有效配置、revision及capabilities。设置页进入时读取；不因为本功能新增一个必须等完的首屏请求。
- `PATCH /api/ui-preferences/opening-animation`：提交 `{baseRevision, openingAnimation}`。更新仅覆盖开屏子字段，不替换其他偏好或任何业务记录。
- 配置结构建议：`openingAnimation: {schemaVersion:1, enabled:true, config:{...}}`，外层维护`revision/updatedAt`。
- `capabilities.canConfigureOpeningAnimation`供界面显隐；服务端依据主应用的主账户身份再次校验。若现有主应用没有角色字段，应以服务端指定的不可变主账户ID作为首期允许名单，不能硬编码用户名或仅由前端布尔值授权。
- 401走现有认证逻辑，403禁止保存，409保留草稿并提示已有新配置/重新读取，422指出字段范围，5xx保留草稿可重试。服务端拒绝非法值；前端输入夹取用于可用性，不替代校验。
- 成功回包包含规范化后的当前配置与新revision；前端以回包更新已保存值。不同设备下次启动取有效配置，不把旧缓存当作永久真实配置。
- 可离线预览与编辑；本期离线保存只保留当前设备草稿并明确未同步，不能冒充账户保存成功。联网后用户显式重试。
- 本机开屏缓存按账户ID隔离。退出/切换账户时取消预览和挂起写入，不把另一账户草稿带过去。没有缓存或身份尚未确认时显示通用默认画面；账户确认后才使用该账户有效偏好。

不改变现有认证及 `revealUserSession()`就绪点。关键页面安全就绪就退出；动画设置读取失败不妨碍进入可用首页。图像、雨点、设置同步不成为额外开屏屏障。

## 后续开发拆分

1. 外观偏好数据与权限：增加独立配置结构/读写接口、主账户能力、账户缓存隔离、范围与修订校验。
2. 设置页：沿用现有设置路由，基础/高级分组、实时预览、草稿/保存/取消/离开处理；关闭开关与减少动态效果联动。
3. 开屏接入：使用相同GlassRain引擎与默认值；静态回退、就绪即退出、失败暂停、dispose清理；复用已加载背景，不另加首屏请求门槛。
4. 实施阶段确认：真实主账户与普通账户权限、跨设备保存、失败保留、版本迁移、减少动态效果、低端设备开销和API就绪路径。此处是未来验收清单，本轮未启动测试。
