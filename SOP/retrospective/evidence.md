# 复盘证据核对

归属：[迭代复盘](../iteration-retrospective.md)。只核对支撑本次结论的事实，不默认建立逐命令流水。

## 对象与来源

- 固定起点、终点、截止时间、时区及排除范围；区分 commit、tree、tag 对象和 tag 指向的提交。
- 项目记录使用[六位简称及对象类型](../../knowledge/coordination-control-plane.md#项目记录的哈希与集合差量)；Git 内部及协议标识不截断。
- 优先取当时机器回执、Git 对象及原始观测；阶段报告与其交叉核对，聊天说明用于确认意图，不替代实际结果。
- 源之间冲突先核对时间、对象和环境；无法证实保留未知，不选择更有利的结论。
- 只引用影响决定的 Owner 原话；仅有摘要时注明来源，不反推缺失授权。

## 按需核对

| 结论 | 原始依据 |
| --- | --- |
| 提交、集成及差分 | git log/show/diff、必要 reflog、工作树及 stash；区分净差异和中间改动 |
| 候选验证 | 适用对象、命令、环境、结果及限制；不把旧候选通过转写给新候选 |
| 推送、tag、发行 | 远端实际引用、tag 目标、Release URL 与正式发行记录 |
| 部署、恢复、观察 | 运行身份、动作回执、备份／恢复结果、样本与窗口；代码回滚不等于数据恢复 |
| 等待、返工、重复动作 | 仅记录改变判断的事实；无起止证据不填耗时，不以提交时间推算开发时长 |

失败保留原错误、发生环境、是否进入业务断言、副作用和后续去向。后来的成功不能覆盖原失败；修复、绕过、回滚和接受限制须区分。

报告只保存可观察的证据、判断结论和动作，不记录隐藏推理过程。凭据、Cookie、私钥、用户私密正文不进入报告；命令只保留安全结构与结果。

完成时核对提交存在、标签目标、差分范围、文件与链接、表格／代码围栏、敏感数据以及未提交内容归属。完整文件清单仅在明确要求或对审计必要时引用已有 Git 输出，不为每次复盘复制一份。
