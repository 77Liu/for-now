## 值得参考的写法

- 将生产链路与消费链路分开，把审核阶段、写入时机和最终展示结果连接起来。
- 给出候选获取、去重、选择、透传、结构化存储、打包和渲染的关键细节，而非停留在“新增图片支持”。
- 枚举搜索头卡、拆卡、Feed、Push 等消费面，包括无需修改的消费者及其理由。
- 用协议示例、具体字段路径、代码落点和函数级“复用 / 不直接复用”说明可实施性。
- Mock 只替代选图结果，保留正式校验和下游链路；测试覆盖非法输出、随机可复现性、兼容和真实依赖切换。
