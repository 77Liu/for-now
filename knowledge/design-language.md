# 此刻：设计语言与哲学

状态：**用户确认的 v0.2 可实装设计基线**。本文件沉淀本轮首页设计交互中的明确偏好；原型尺寸、颜色与技术细节属于实施决策，可以在不破坏这些原则的前提下调整。这里的 v0.2 是设计基线，不代表生产已发布。

## 1. 产品应该带来的感受

打开此刻，可以立即留下一个想法，也可以安静地遇见自己曾经留下的内容。界面帮助记录与回望，不催促表现，不把生活变成成绩单。文化感来自留白、节奏、材质与内容，不靠生僻名字或大量诗句装饰。

## 2. 已确认的设计偏好

- **浅色水墨丹青、宋式美学。** 用户喜欢山水与竹子，且反复强调“要浅”。使用近白宣纸底、低饱和灰绿山水、稀疏竹影；主体文字清楚。宋式是美学方向，不宣称精确复原历史器物或字体。
- **旧 UI 是 demo 的精力取舍。** 真实页面必须作为功能与导航参照，但旧的卡片、配色和布局并非新设计的不可变约束。不能将“基于现状”误解为“只能润色 demo”。
- **首页突出核心功能入口。** 四项核心为记录思考、近期状态参考、用户已有内容随机呈现、小物。完整量表和完整思考表单按需展开或进入，不占满默认首屏。
- **弱模块感。** 内容自然进入同一张纸面，用网格、行距和少量细线组织；避免每项功能一个边框、一张卡片、一个大标题。
- **功能明确时不重复命名。** 首页不显示“最近状态”“随机回看”等栏目名，也不换成同样多余的诗化标题。按钮入口仍要明确：“记录思考”“记录状态”“查看趋势”“查看原文”“小物”。来源、日期、指标图例可保留，它们提供证据而非命名装饰。
- **状态趋势只做参考。** 用户明确担心低状态带来负反馈。因此降低首页曲线的面积与视觉权重，不显示成绩、红色警报、涨跌奖励、连续打卡压力或“你变差了”一类评价。详细数值由用户主动打开。
- **小物入口已获认可。** 保留小幅纸品/实物缩略图和清楚的入口，实装优先复用用户真实小物及抠图，不扩大成装饰拼贴墙。
- **留白不等于空洞。** 横版需要有足够已有内容：思绪、阅读笔记、拾句有长短与主次，保留真实来源。通过增加有价值的内容改善空旷，不靠重复文案、统计卡片或加深背景填满空间。
- **手机独立排版。** 桌面多列、手机单列，维持可读字号与触达；手机不缩小桌面截图，不把三条内容强塞进固定首屏。

## 3. 内容与数据的伦理

首页随机呈现用户已有、可访问且未删除的内容；优先使用用户原文和明确收藏。AI 应答、摘要与人格推断不可混成“你曾经说过”。书籍原文、读者笔记与 AI 派生内容必须区分来源。

低状态仍是合法的真实经历。不通过筛除低值、补齐高值、改变轴域或人为平滑走势制造“变好”；视觉弱化不得篡改数据。首页省略刻度时，详情提供真实量表与时间。缺失记录保留缺失，不能补零；同日多次按项目既有日均口径聚合，见 [metrics.md](metrics.md)。降低负担是设计意图，尚未被用户研究证明能消除负反馈。

随机内容不自动刷新、漂浮或滚动，不打断正在阅读的人。正文长时做有限摘要并提供原文，不使用绝对坐标让不定高文本重叠。不为了“积极”悄悄删除或重写用户内容。

## 4. 视觉与交互规则

1. 页面优先级：记录思考 → 用户内容 → 小物 → 轻量状态参考。
2. 背景是环境，不是内容。纸面中心保持干净，山水集中边缘/底部；竹子稀疏，不能压住正文或侵占触控区域。
3. 宋体用于品牌、主标题与核心原文；来源、表单和辅助说明使用清晰系统字体。禁止文字栅格化进背景。
4. 主操作使用低饱和灰绿、细边框与适度圆角；正文区无卡片阴影。必要的编辑层与详情层可以有明确容器边界。
5. 小字仍可读。浅的是背景和辅助曲线，不是正文与按钮。保留键盘焦点、语义标签、手机 44px 触控目标与安全区。
6. 点击进入后才展示完整编辑或详情；关闭后返回触发点；未提交草稿不因收起或换组丢失。
7. 保存仅刷新有关内容。查看、换组和记录不能导致整页重绘或清空其他区域。

## 5. 本轮交互如何收敛

| 阶段 | 用户反馈 | 最终沉淀 |
| --- | --- | --- |
| 初稿 | 未参考当前项目，几乎没有参考意义 | 先核对真实项目目录和在线界面，理解功能与导航 |
| 基于正式页的卡片稿 | 旧 UI 属 demo，既然做好就重新做 | 保留功能证据，放开视觉重设计 |
| 宋式浅色稿 | 喜欢浅色山水、竹子，模块感不要强；标题出戏 | 弱化容器与栏目名，入口名保持直接 |
| 桌面与手机稿 | 状态只是参考，小物不错，横版偏空 | 缩小曲线、保留小物、增加多源内容；手机单列 |
| 本次确认 | 当前设计稿 v0.2 可实装 | 以可运行 HTML、双端背景和本文作为前端基线 |

初稿与卡片稿仅为历史探索，不应覆盖本文件的当前结论。命名表仍以 [cultural-content-preferences.md](cultural-content-preferences.md) 为准；本文件负责视觉与体验哲学，不重复维护导航词表。
