# 模块迁移与接入审查

归属：[模块设计](../modularization-design.md)。本表用于找消费者，测试选择仍只由[测试影响矩阵](../test-impact-matrix.md)决定，不另建测试门或报告链。

## 影响定位

| 变更类型 | 必查模块或资产 | 需核对的行为边界 |
| --- | --- | --- |
| 数据字段、默认值、版本或迁移 | 领域 schema/repository、持久化、备份恢复、管理聚合、文档 | 旧数据、空数据、损坏数据、回滚读取、账户隔离 |
| API 路径、参数、响应或错误码 | 后端路由/服务、前端 API、页面调用方、认证、代理、测试 | 新旧客户端兼容、base path、权限、失败响应 |
| 认证、会话、账户切换 | `auth`、所有受保护 API、附件、SSE、前端状态、部署代理 | 未登录、越权、跨账户、旧请求取消、登录恢复 |
| AI 场景或模型参数 | AI、Prompt、设置、任务、通知、用量、费用、审计、调用页面 | 幂等、截断、失败、重试、计费、敏感信息 |
| 后台任务状态 | 任务、目标领域、通知、重启恢复、监控 | 重复请求、运行中断、过期拒写、直接重试后继 |
| 删除或恢复 | 目标领域、回收站、附件、任务失效、审计、管理聚合 | 取消、恢复版本推进、永久清理、附件失败重试 |
| 附件结构或上传 | 媒体 UI、附件服务、领域引用、OSS、配额、回收站、备份恢复 | MIME/大小、越权、孤儿对象、失败清理 |
| 时间与日期语义 | 时间共享模块、领域 schema、排序、指标、页面显示 | 时区、跨午夜、旧记录、创建/发生时间分离 |
| Markdown 或可见文本 | 内容渲染、批注坐标、预览、所有内容页面 | XSS、LaTeX、源码/纯文本坐标、锚点漂移 |
| 导航、页面 ID 或 DOM 根节点 | HTML shell、页面注册、样式、通知跳转、移动导航、UI 测试 | 深链、返回、窄屏、键盘、安全区 |
| 样式令牌或共享组件 | tokens、组件、所有消费者、截图矩阵 | 桌面/移动、长文本、空状态、焦点、无重叠 |
| 环境变量或启动配置 | config、服务启动、systemd、部署脚本、示例配置、文档 | 缺失值、非法值、生产默认、回滚版本 |
| 日志、指标或隐私字段 | 业务模块、observability、中台聚合、导出/删除、隐私文档 | 脱敏、权限、保留期、TraceID、正文不泄露 |

## 迁移顺序

1. 确定当前切片基线、要迁出的职责、目标 owner 与受影响消费者；复用仍有效的契约和行为证据。
2. 先处理阻塞该切片的共享契约，再搬迁实际实现。低耦合与高耦合链路按依赖排序，不照搬旧版本的 G1/G2 排期。
3. 同步公开入口、模块登记、消费者及必要验证。新实现可用后移除旧实现；兼容例外保留明确删除条件。
4. 开发者自查后，由主控独立审查；验证确认结论。接入、失败返回及证据复用见[协作协议](../../SOP/multi-agent-orchestration.md)与[集成 SOP](../../SOP/integration-audit.md)。

共享契约和高耦合链（认证/会话/存储、思绪/批注/任务/通知、回收/附件/恢复、时间/排序/指标）先明确单一写者与接入顺序。只有写集和契约支持真实独立时才并行，不能仅凭目录不同判断。

## 防止热点平移

- 旧入口确实移除了该职责；新 owner 与登记一致，未把领域判断重新聚合到新的巨型 runtime/coordinator。
- 状态与资源只有一个 owner；取消、清理、重置、重启及失败恢复的实际消费者一致。
- 导入、测试、页面事件与真实加载闭包指向新 owner，无深层导入、循环依赖或隐式注册。
- 对原热点及迁入模块核对规模、可变状态、请求/DOM/event/timer、依赖及写者。按本次迁移风险选择证据，不能仅以旧文件行数下降宣称完成。
- 行为变化与纯搬迁分清；数据、权限、原文、版本、附件关系和错误契约不得因机械拆分漂移。

结构性迁移未完成时，如实保留已授权范围内的例外和限制。未纳入的技术债不自动成为本切片 BLOCKED；若它实际阻止验收或造成数据/权限风险，按矩阵及发布 SOP 阻断对应动作。

迁移收口检查登记、目录、公开入口、消费者、例外与有效证据一致。只有明确承诺全量迁移且实际完成时，才能声明例外清零；不固定双轮审计、不重复运行未受影响测试。
