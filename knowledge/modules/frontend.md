# 前端模块职责

归属：[模块设计](../modularization-design.md)。数据缓存、分页/详情、预取和交互保护只在[设计契约](../design-contracts.md)维护；本文件规定它们由谁负责。

## 页面、功能与共享层

| 区域 | 职责 |
| --- | --- |
| app / kernel | 构造公开能力、导航与生命周期装配；不承载保存、回答登记、测试数据装载等业务实现 |
| pages | 页面挂载、卸载、路由和功能组合；不拥有跨页面复用规则 |
| features | 一组用户操作的 controller/view/必要局部状态，对外公开命令与生命周期 |
| api | base path、HTTP/SSE 协议、错误与取消 |
| session | 账户/会话代次与请求失效边界 |
| state | 唯一实体缓存、记录增量合并、订阅和失效；不维护并行快照系统 |
| ui / content | 通用控件、弹层、可见文本、Markdown/LaTeX 与转义 |
| media / time | 媒体输入与资源生命周期、日期显示与跨日处理 |

页面分组与具体视图用现有页面登记维护，不在本文再复制一份视图列表。功能不得操作其他功能的私有 DOM、定时器或局部状态。

## 生命周期和加载

首次引入状态、请求、事件、timer、草稿或外部资源时，明确 owner，以及应用、账户、会话、路由、对象中的作用域；说明创建、取消、清理、账户切换、重试与重启行为。

Controller 根据实际需要提供 mount/render/unmount/resetSession；纯规则模块不机械套 controller。组合入口不吸收清理规则或领域判断，不使用万能 context、service locator 或隐式扫描注册。

首屏可见能力可以静态加载；隐藏能力按需加载，核对实际依赖闭包和 PWA 缓存策略。不能仅增加动态 import，却仍由首屏静态依赖拉入同一能力。

CSS 根文件保持稳定入口；令牌、基础、通用组件、功能和页面样式按职责维护。页面/功能选择器有稳定作用域，不通过无作用域标签选择器修复局部问题。

新源码、构建产物隔离和公共接口注释遵循[工程规则](../engineering-rules.md)与[源码规范](../source-documentation-rules.md)，旧原生 JavaScript 的存在不构成新增 JS 的理由。
