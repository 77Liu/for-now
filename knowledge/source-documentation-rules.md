# 源码与接口文档规范

整理修订：2026-10-17，Owner 已批准，接入 develop 后生效；既有文件头／JSDoc 规则自 2026-10-13 生效，partial 规则自 2026-10-14 生效，搬移不重置生效时间。本文是新建源码文件头、公共接口 JSDoc 与 partial 提交治理的唯一正文；工程规则、任务 SOP 和审查清单只引用本文件。

## 源码文件头

所有新建源码文件必须有简短文件头，说明文件职责、建立时间和状态；存在账户隔离、状态归属、异步生命周期、恢复或其他重要约束时，补充必要的关键边界，没有时不机械填充。

- **文件职责**：说明该文件负责什么。
- **建立时间**：使用 `YYYY-MM-DD`，指首次建立日期，重命名不重置。旧文件首次建立时间无法可靠确认时注明“未知”，不得使用补注释当天的日期。
- **状态**：仅使用 `active`、`experimental`、`deprecated`。

| 状态 | 含义 |
| --- | --- |
| `active` | 正常维护，允许新增调用；不代表已发布、已验收或生产已启用 |
| `experimental` | 试验能力，兼容性尚未承诺 |
| `deprecated` | 仅保留兼容维护，禁止新增调用；必须注明替代入口或保留原因 |

文件头不维护作者、最近修改时间、最近修改版本或变更流水，这些信息通过 Git 查询。注释放在 shebang 等语言必需前置声明之后，使用适合该语言的注释语法。

```ts
/**
 * 通知页面的加载、呈现与用户操作协调。
 * 建立时间：2026-10-13
 * 状态：active
 * 边界：仅处理当前账户；异步结果不得写入已失效页面。
 */
```

## 公共接口文档

公共接口是供其他模块或外部调用方使用的导出能力，不等于所有内部函数。新增公共接口必须维护 JSDoc，说明用途，并按实际需要说明参数、返回值、副作用、错误及关键约束，避免复述类型或显然代码。

- 新增公共接口维护 `@since`：填写首次正式发布可用的版本；尚未发布时使用 `@since unreleased`，正式发布时更新为实际发布版本。
- 后续普通修改不改写 `@since`，不维护“最近修改版本”。
- 废弃接口使用 `@deprecated`，注明替代方式或保留原因。
- 旧接口在相关实现切片中逐步补齐；无法核实首次发布版本时暂不填写 `@since`，不得猜测。

## partial 提交治理

生效：2026-10-14。本段是部分验收、暂不使用或保留待启用代码的提交治理唯一正文。

- 这类代码仅在Owner明确授权对应范围后允许提交；费用授权、具备源码或类型检查通过不等于启用或验收授权。授权来源随已有控制面事件记录，不新增审批表或报告链。
- 文件头及受影响公共接口JSDoc必须显式注明 `@partial`、`@partialScope`、`@partialVersion`、`@partialReason` 和 `@partialAuthorization`；存在暂不用、默认关闭或特定环境限制时，补充 `@partialUsage`。中文说明具体未验收/不可用范围，不能只写一个无范围的partial。
- `@partialVersion`记录本项partial所属候选/版本，未发布时明确候选身份；不是“最近修改版本”。`@partialAuthorization`引用Owner决定，不能将Agent自行判断作为授权。
- partial是验收/使用范围标记，不新增第四种文件生命周期状态；文件仍按active、experimental、deprecated分类。仅准确率未完整验收，不得写成整个接口不可用；暂不用的分支不得借提交自动启用或成为默认回退。标注必须与真实配置和实现一致。
- 消费者和接入者必须核对被调用能力是否落在获准使用范围；未授权、不安全或破坏实际调用契约的半成品不能靠partial标记合入。已有失败不能通过标注洗成通过。
- 完成对应验收后，沿已有审查及控制面入口关闭partial并同步注释；历史原因与授权通过Git、原事件追溯，不在文件头累计流水。
- 本规则从本次更新起执行，只补本切片相关源码；仅标注不改变返回协议、不建立新的运行状态或专项测试。自查、接入和发布审查沿用本节入口。

## 实施与审查边界

- 自生效起，新源码立即遵守；旧源码仅在相关实现切片中逐步补齐，不开展全仓补注释或额外重构。
- 生成物和第三方源码不适用，不手工修改生成文件的注释。
- 文件头和 JSDoc 必须与实际实现一致；职责或关键边界变化时同步更新。
- 本规范不替代现有 TypeScript、构建产物隔离与 Git 管理规则。
- 开发者自查、主控接入审查及发布前检查使用本节；仅为注释规则不增加专项测试，不重复运行未受影响测试。
