# 长期资料

本目录保存跨版本仍用于产品或技术判断的长期材料。仍在指导后续工作的文档直接
放在本目录根部，并在正文标明 `design`、`idea` 或 `philosophy`；已经被实现、
替代或不再代表当前系统的材料按类别进入 `outdated/`。过期材料只用于追溯，
不能覆盖当前领域知识、代码和协调控制面。

## 进行中

| 类别 | 文档 | 使用边界 |
| --- | --- | --- |
| philosophy | [产品哲学与核心价值](product-philosophy.md) | 长期产品判断原则 |
| design | [个性化回答、用户模型与感知系统](personalization-and-perception.md) | 理想设计与后续演进参考；实际能力以当前代码和领域文档为准 |

## 已过期

- [design](outdated/design/)：启动、媒体、视觉等已被实现或替代的设计时点。
- [ideas](outdated/ideas/)：尚未形成当前计划的探索与模拟基线。
- [philosophy](outdated/philosophy/)：被新长期原则替代的历史哲学材料。
