# 迭代历史

本文档保存已完成的重要项目变化。README 只保留当前状态和本文件入口，不重复维护完整历史。

## 2026-09-27

- 新增工程与代码规则的单一事实来源，明确最小正确改动、反过度设计、边界验证、诚实交付、原子提交及当前单维护者主分支策略；项目规则文件改为约 100 行、最多 300 行并定期清理。
- 新增“小物收集”：自动识别照片主体并生成透明 PNG，原图独立保留；轮廓可调边缘余量，也可用保留/擦除画笔、撤销和清空手动修正。画廊默认展示透明轮廓，放大后默认查看原图；数据结构升级至 v12。
- 首页新增每日记录；善言支持标签、原始换行、均摊标签的无重叠回顾气泡与选区直接收藏；数据升级至 v11，模型设置升级至 v4。
- 新增“关于”页，以产品定义为单一事实来源，呈现价值主张、系统闭环、四类记录、产品边界和可修正原则；模型设置升级至 v3，严肃回答默认使用 Ultra、一般对话与批注使用 High、轻量提示和识别使用 Lite/Mid，各场景提示词均以“判断密度优先”并独立限制篇幅。
- 重构读书页：空书架保留放大的截图识别入口，有书后切换为回顾气泡与封面画廊；书籍详情以时间线管理“记录 / 附加思考”，滚动后收拢标题与书目信息并突出随机笔记，支持无收藏、星标、萌芽三档状态及增删改查，正文继续复用划线、评论和 `@神鸡`。
- 数据结构升级至 v9；旧读书笔记自动补齐发生时间、记录类型与收藏状态，并在编辑或删除正文时复用批注重定位和漂流保护。
- 日记助手新增“给我引子 / 给我结构 / 给我一个话题”，均结合近期记录与当前已写文字生成短提示并只追加到编辑器末尾；已补足思考输出预算，首轮只有思考而无正文时会自动关闭思考重试。
- 认知复盘明确采用追加式持久化；回顾页新增历史总数和可折叠历史列表，最新复盘默认展开，旧复盘及模型思考可随时回看。
- 修复善言收藏后异步访问失效事件对象导致的界面中断；保存后立即清空、刷新并提示成功。善言与思绪时间线改为同日只显示一次左侧日期，每条记录右侧显示本地时间。
- 修复书目截图入口无可见上传状态的问题；现在支持点击选择、直接粘贴、拖放、格式与大小校验、缩略图预览和识别结果回填。
- 修复认知复盘直接显示 Markdown 源码的问题，并统一补齐思考问题、模型思考、对话消息、捕念、书目简介和读书笔记的 Markdown/LaTeX 渲染。
- 新增“捕念”碎片收集箱和独立时间线，可无结构快速保存，并把捕念带入初步想法继续形成完整思考。
- 新增日记助手：自由书写、五类可选引导、标签与历史编辑；可对已保存原文生成流式回望，回望版本及模型思考独立持久化。
- 数据结构升级至 v8；事件记录以 `occurredAt` 保存完整发生时间，`occurredOn` 仅作本地日期索引，`createdAt` 保留为不可变创建时间；捕念与日记进入长期个人语境，但任何模型思考仍不进入上下文。
- 明确思考为“问题—初步想法—回答”的主题链，并将主题写作、捕念知识图谱与发散辅助记录到 `README-TODO.md`。
- 选中文本后可选择“评论”或“划线”；批注与 `@神鸡` 已覆盖主题思考、捕念、日记原文与回望、长期对话、认知复盘、书目简介、读书笔记和善言。
- 评论与划线列表新增批注级 `@神鸡`：自动读取原始问题、标记内容及前后文，支持空问题直接分析与连续追问。
- 折叠预览不再暴露 Markdown 标记；批注新增上下文锚点，正文编辑后可平移，无法可靠定位时保留原始上下文与评论记录至“评论漂流箱”。
- 修复 UTC 日期导致午夜后仍停留前一天及时间显示错误；旧记录执行一次性本地日期迁移。
- “给我回答”改为 SSE 流式展示思考与回答，回答开始时折叠思考；关闭弹窗后任务仍在后台完成并持久化。
- 精简思绪详情：隐藏空的初步想法，原始回答提供五行 Markdown 预览，追问表单改为按需展开，保留/舍弃操作按当前状态互斥显示。
- 记录保存与自动回答解耦；后台生成不再锁住录入表单，可继续提交新的思绪。
- 模型思考支持独立持久化和回答旁按需展开；流式生成时允许用户向上阅读，不再强制拉回底部。
- 修复 Markdown 回答跨加粗、列表等结构时无法评论或划线的问题，批注统一锚定到渲染后的可见正文。
