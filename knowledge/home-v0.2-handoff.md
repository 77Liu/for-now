## 视觉 token 与布局

| Token | 基线 | 用途 |
| --- | --- | --- |
| paper | `#faf9f5` | 图片加载失败时仍可用的浅宣纸底 |
| ink | `#282f28` | 正文 |
| muted | `#646a60` | 来源、日期、辅助文字 |
| moss | `#40593b` | 操作和选中态 |
| sage | `#e6e9de` | 浅按钮底 |
| hairline | `#dcded5` | 少量分隔线 |
| serif | Songti SC → Noto Serif CJK SC → STSong → SimSun → serif | 标题与原文 |
| sans | 系统 UI / PingFang SC / Microsoft YaHei | 辅助信息与表单 |

字体具体显示依设备而定；正式跨平台字体可后续另行选型，不为本轮引入外网依赖。正文最小 16px（手机），来源最小 11px。正文/交互文字目标对比度 ≥4.5:1；曲线只是辅助图形，详情另提供可读数值。背景不能用来承载文字。

- 桌面 >1100px：148px 左导航，主内容最大 1250px；内容双列，左侧主思绪、右侧笔记与拾句。小物左下，状态参考右下。
- 平板 761–1100px：115px 左导航，内容双列缩小间距，状态操作移到曲线下方。
- 手机 ≤760px：去左导航，底部四项固定导航；保留顶部三个组内入口；内容单列两条，较长正文限三行，点击原文展开。`env(safe-area-inset-bottom)` 预留底部空间。
- 手机首屏容量随字体/屏幕而变化，允许自然滚动；不得为塞满一屏缩小字体。页面最大内容高度不固定，正文在正常文档流。
- 44px 最小点击高度；键盘焦点可见；原生 dialog 提供焦点约束，Esc 关闭，关闭后返回触发按钮；无自动轮播；动效仅 150ms 悬停色变化，响应减少动画偏好。

## 交互与实装路由

| 界面入口 | 原型 | 真实接入位置 |
| --- | --- | --- |
| 记录思考 | dialog 必填问题、可选想法/回答；收起保留本次草稿 | 现有 `#chain-form` 的问题/想法/回答链；入口展开或路由至编辑层，复用现有保存与后台回答 |
| 换一组 | 按类型抽样，尽量不重复当前组；只替换内容区 | 当前账户的思绪、书笔记、拾句；源 ID 与类型必须保留 |
| 查看原文 | 原文 dialog | 真实所属页面及条目；思绪应带完整链，不能只打开截断摘要 |
| 小物 | 小物示例详情 | `switchView('keepsakes')` 及既有列表、附件详情 |
| 记录状态 | 显式选择情绪，不预选；演示同日均值 | 现有 `#checkin-form`，正式仍为四项状态、确认规则、备注/因素与可编辑发生时间 |
| 查看趋势 | 主动查看数值表 | `switchView('review')` 与长期趋势；真实统计口径见 metrics |
| 今日/所见/所思/我的 | 可点开的路由关系说明 | 既有 section/view 映射及 `switchView`，保留选中态 |
| 共参/每日 | 路由说明 | `switchView('together')` / `switchView('daily')` |

正式源码入口为 `public/index.html`、`public/frontend/app/runtime.mjs` 与 `public/frontend/styles/application.css`；原型使用 `data-route`，正式页继续使用既有 `data-view` 路由。原型中的样例路由说明和数据没有进入正式首页，二级页面沿用原功能。

## 数据接入约定（适配层建议，不是新增服务端 API）

```js
// 由现有 state 适配；不要为此原型新增独立数据库/接口。
{
  id,                 // 源记录稳定 ID
  type,               // thought | book | quote
  source,             // 来源、书名及可追溯日期
  title, text,        // 用户原始内容，摘要仅做展示截断
  full                // 原型使用；生产以原始详情查询为准
}
```

用 DOM textContent 或既有经过安全处理的 Markdown 渲染，不能将用户内容直接拼 innerHTML。先排除已删除、不可访问内容，再抽样；不足三个则展示实际数量，不制造 AI 填充。手机换组仍覆盖可见两条，第三条通过再次抽样可见，不为首页制造无限下拉列表。

状态按自然日归组，同日多次逐项平均；缺失不补零、不跨缺失日连线；仅一条记录画点不画趋势。首页无 y 轴、无成绩分，详情保留量表与时间；固定量表范围，不随高低值自动缩放以夸大波动。无记录显示“还没有记录”。仅替换受影响 DOM，不能重置其他草稿。

## 生产接入边界

1. 将 CSS 变量、布局规则限定到 `.home-v02`，避免原型中全局 button/main/dialog 样式影响二级页。保留现有导航与权限边界。
2. 原型的 `body::before` 背景层应移为首页容器装饰层；退出首页不显示该背景。移动端使用独立图片，`aria-hidden`、不接收指针事件；图片失败仍有纸色背景。
3. 页面由 flex/grid 自然排布；不要把设计截图作为整页背景或绝对坐标定位文本。
4. 小物纸品为原型中的内联 SVG/CSS 示意。正式使用当前账户真实缩略图，保留图片权限、懒加载、失败状态；没有小物时保留入口，不假造收藏。
5. 生产删除“原型”“示例”“刷新清空”等开发说明；保留真实保存成功/失败反馈。模型后台调用、鉴权、数据增量刷新与删除恢复沿用原有契约。
6. 设计版本不解除已有模块化开发准入门禁；正式接入按现有排期串行推进，不修改正在进行的底座工作。

## 必验情况

- 桌面 1440×1000、平板 900px、手机 390×844 及 320px：没有横向溢出、文字交叠或导航遮挡；长内容可读。
- 换组后页面位置和未提交草稿不变；无内容/不足三条可用；打开原文可追溯。
- 收起/Esc 保留草稿，保存必填校验，成功仅局部更新；关闭层焦点返回入口。
- 状态未选择不可保存；同日多次不覆盖历史；低状态不触发额外红色或激励文案；详情数值可用。
- 背景断网/缺失时页面仍可操作；手机安全区、键盘、滚动与系统放大字体不被固定高度截断。

正式接入证据由 `scripts/frontend-shell-regression.mjs`、`scripts/ui-regression.mjs` 与完整系统测试维护。本规格继续区分原型示意和正式数据边界。
