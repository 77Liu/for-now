## 历史生产基线（v0.1.1）

- `server.mjs`：无框架 Node HTTP 服务、JSON API、DeepSeek 调用、阿里云图片分割、火山语音/视觉装配与统计计算。
- `logging.mjs`：请求、持久化、操作和 AI 审计共用的脱敏、私有 NDJSON 队列、资源摘要与日文件清理。
- `attachment-storage.mjs`：本地或私有 OSS 附件后端；云端按账户使用对象前缀，读取统一经过应用认证代理。
- `public/`：单页 HTML/CSS/JavaScript 界面。
- `data/store.json`：状态、每日健康记录、捕念、日记、思绪、对话、书目、小物、善言、实验、复盘、回收站、待重试附件清理、后台任务、通知、冷启动资料与商业化估算参数；生产结构版本为 v14。

## 当前生产架构（v0.5.5，继承 v0.2.0 模块化底座）

模块边界和检查规则见 [`modularization-design.md`](../modularization-design.md)；领域职责、实体访问、事务与同步目标契约见 [`design-contracts.md`](../design-contracts.md)；PostgreSQL、后台 worker、个人上下文与按指标扩容的目标方案见 [`scalable-architecture-design.md`](../scalable-architecture-design.md)。本文件中的“当前生产架构/工作区结构”是事实记录，不覆盖目标契约；未迁移的整账户读写和整域同步必须标为待迁移。

- `server.mjs`：保留无框架 Node HTTP 装配入口；G2 R4 候选已将目标领域规则迁入模块、应用与 HTTP 层，模块迁移例外清零。
- `src/shared/persistence/`：JSON/PostgreSQL repository、业务/身份/配置/用量映射、原子注册、附件状态、整批迁移与停写导出；业务模块不直接拥有数据库连接或 JSON 写队列。
- `src/modules/thoughts/`：接管思绪根链/内容块、保留状态、备注、追问、乐观版本和回答结果保存；`src/app/thought-workflows.mjs` 编排创建链/任务原子写、草稿/引子与前台回答，`src/http/thoughts.mjs` 同时适配旧 API 和 v1。
- `src/modules/annotations/`、`tasks/`、`notifications/`：分别拥有批注锚点/漂流/回复、任务幂等/重试/恢复、通知已读与计数。`src/app/` 解析跨领域资源，并在同一事务中校验输入、保存结果、更新任务与通知；`src/http/` 适配任务和两套兼容批注 URL。请求账户上下文由装配入口传入调度器。
- `src/modules/auth/`：账户、密码与会话生命周期；只通过注入的认证 repository 和初始化接口访问持久化。`src/http/` 负责 Cookie、身份绑定、认证路由、JSON 解析与 SSE 事件；注册事务提交后才向客户端发出 Cookie。
- `src/modules/trash/`：回收条目、保留期限、幂等查找和父子清理清单。`src/app/trash.mjs` 协调业务位置解析、版本推进和批注回附，`http/trash` 拥有响应适配。`shared/attachments` 负责引用识别和清理任务尝试，`app/attachment-cleanup` 在账户锁内登记持久任务、重试与重启恢复。批注后台任务同时绑定根记录版本，恢复相同正文也不能接受删除前回答。
- `src/config/`：统一环境解析、默认值、上下限与启动模式互斥检查；配置在启动时形成快照，存储适配器显式接收配置。
- `src/shared/observability/`：异步上下文、请求/持久化/AI 审计共用的脱敏、私有 NDJSON 队列、提交后资源摘要与日文件清理；`http/request` 拥有追踪 ID、base path、受控异常与请求完成审计。根 `logging.mjs` 已移除。
- `src/modules/discovery|exports|actions|feedback/`：分别拥有思绪检索/回访、跨体裁导出、行动/习惯及产品反馈/验证台账；均通过注入的账户仓储工作，不直接访问 HTTP、文件或数据库。
- `src/http/api-v1.mjs` 与 `src/http/openapi-v1.mjs`：冻结 v1 `1.0.0` 的 `data/error/meta` 包络、TraceID、游标、ETag/If-Match、Idempotency-Key、模块注册及 OpenAPI 根结构；新增账户增量同步与客户端操作终态查询。
- `src/modules/ai/`：四档/场景设置、用量/费用快照、成本模拟/统计、额度、通用 SP/场景契约与逐次调用/重试审计；存储、日志和供应商接口由装配注入。JSON 设置修改串行读取最新值，写失败不提交摘要；账本/审计失败不重试模型。设置与成本路由归 HTTP，跨领域上下文和具体业务 Prompt 继续迁移。
- `src/infrastructure/ai-providers/`：DeepSeek HTTP/SSE、阿里云分割，以及火山 V4 签名、OCR/文档解析、TTS 和流式 ASR 传输；不含业务重试、费用或记录保存策略。图片与私有音频读取归共享附件模块。
- `src/modules/keepsakes/`：小物校验、归一化、创建/编辑和分割流程，只接收小物集合仓储或注入的供应商/临时文件接口；四条小物路由归 HTTP，删除调用应用回收事务。`shared/concurrency` 提供无业务含义的 QPS/在途队列，AI 与分割各自独立装配。
- `src/shared/time/`：本地日期、跨日计算、严格日期校验、本地日期/时分组合和发生时间解析；历史 store 版本的日期修正仍在迁移处。旧日期解析兼容与 v1 契约收口分阶段处理。浏览器侧无业务时间格式化由 `public/frontend/time/` 提供。
- `src/shared/time/` 与 `src/shared/validation/`：本地自然日/日期偏移、数字范围与通用校验；保持账本配额既有 UTC 日口径。
- `src/shared/attachments/`：本地、mock 与私有 OSS 附件适配，图片/音频文件签名校验、配额锁、上传清单和临时文件生命周期；账户目录与数据库清单由装配入口注入。云端按账户使用对象前缀，HTTP 上传与 GET/HEAD 读取归 `src/http/attachments.mjs`，统一经过认证；清理同时覆盖云端与迁移遗留本地副本。捕念音频原件、ASR 原文和 AI 整理稿分层保存，未配置真实 ASR 时明确保持 `ASR_NOT_CONFIGURED`，不以客户端临时识别替代。根目录旧存储文件已移除。
- `public/`：单页 HTML/CSS/JavaScript 界面；根 `app.js` 只启动 `frontend/app`，根 `styles.css` 只加载模块样式。`frontend/pages` 登记 23 个视图并管理组别/页面生命周期，`frontend/features` 组合页面副作用及 discovery/export/actions/feedback 纯功能模块；`frontend/api/session/state/content/time/media` 分别承接传输、会话、状态和无业务共享能力。`index.html` 保持无内联业务逻辑的静态可访问性壳。
- `data/store.json`：状态、每日健康记录、捕念、日记、思绪、对话、书目、小物、
  善言、实验、复盘、行动、习惯/打卡、反馈、验证台账、通用语音缓存、回收站、
  待重试附件清理、后台任务、通知、冷启动资料与商业化估算参数；当前工作区结构
  版本为 v16。
- `data/llm-settings.json`：四档模型、逐场景档位与思考强度、助手称呼、逐场景
  回答风格、语音偏好与 API Key；当前结构版本为 v10，权限 0600，不返回页面
  明文。
- `data/ai-usage.json`：从统计能力启用后开始追加的逐次 AI 用量、图片/语音/
  文档输入摘要、状态、耗时、当次可得单价快照和费用拆分；当前结构版本为 v4，
  不回填旧调用。火山账单单价未配置时保留调用单位并明确标记费用未知。
- `data/ai-budget.json`：全站 AI 预算、任务预留、结算和阈值事件；JSON 更新使用带残留恢复和超时的跨进程文件锁，PostgreSQL 使用独立预算角色和全局单例行。
- `data/logs/ai-audit-YYYY-MM-DD.ndjson`：按账户和 UTC 自然日保存的完整 AI 调用审计；包含实际 SP、UP、历史、参数、回答与推理，不包含 API Key 或图片 Base64，默认保留 30 天。

应用本地运行于 `http://127.0.0.1:4173/`。所有模型能力走独立 DeepSeek API，不复用开发 Agent/Codex 线程。
首次启动先按锁文件执行 `npm ci`。持久化只在文件不存在时使用默认数据，损坏文件保留并拒绝继续写入；JSON 通过 `0600` 临时文件原子替换，结构迁移前留备份。数据、账户、附件和日志目录固定为 `0700`，其中的私有文件与迁移备份固定为 `0600`。
日期归属使用运行设备的本地自然日，时间戳以 UTC ISO 格式持久化；页面显示时间固定采用 00–23 小时制。事件型记录同时保存不可变的创建审计时间 `createdAt`、可编辑的完整发生时间 `occurredAt`，以及从 `occurredAt` 按本地时区派生的日期索引 `occurredOn`。页面若跨过午夜且用户此前停留在“今天”，应自动切换到新的本地日期。

### PostgreSQL 迁移阶段

- 生产写源已切换为 PostgreSQL；旧 JSON 由写源标记保护并只作为回滚副本，
  不启用长期双写。本地隔离验证仍可显式选择 JSON 或 PostgreSQL。
- `npm run migrate:postgres -- --dry-run --data-dir <path>` 只读校验全领域 JSON 和附件实物，输出账户、SHA-256 和数量，不输出正文或秘密。
- 建表通过 `--init-schema` 和独立 `PG_SCHEMA_DATABASE_URL`；完整导入使用非 owner 的 `DATABASE_URL`，全站预算、所有账户和独立文件在同一事务中校验内容与源漂移。
- 业务集合、嵌套内容、认证/会话、模型设置/秘密、逐次用量、成本方案及全站预算已接入关系行运行读写，并验证进程重启和第二数据库恢复。PostgreSQL 运行使用互异的数据、认证和预算连接；当前每数据库单应用实例，旧思绪投影已移除。这里描述的是当前映射与恢复事实，不代表普通在线命令已经完成实体级精准读写；新增或迁移命令仍必须遵循 [`design-contracts.md`](../design-contracts.md) 的局部闭包和短事务要求。后续结构变更仍需逐版完成备份、恢复和发布授权。
- 所有租户表启用并强制 PostgreSQL RLS；真实 PostgreSQL 16.14 已验证隔离、重复导入、失败回滚和关系重建。表结构、覆盖保护、命令与剩余边界统一见 [`postgres-migration.md`](../postgres-migration.md)。

## 视觉设计语言

全站使用“雾白玻璃 + 石墨文字 + 低饱和功能色”。内容和记录是第一视觉层级，导航只提供稳定定位，不使用大面积深色背景与高饱和装饰。

- 基础色：页面为雾灰白，正文为石墨色，边框使用带少量绿色倾向的浅灰；卡片以 8px 圆角、细边框和轻阴影为主。
- 一级导航固定为“今日｜所见｜所思｜我的”。今日包含“此刻｜共参｜每日”，并在此刻页承载行动/习惯；所见以“念起｜书间｜拾句｜小物”承载捕念、读书、善言和小物；所思包含思绪、寻迹、日记、回顾。“我的”采用设置页式分组列表，数据导出和产品反馈各自进入独立内容页。
- 文化表达与界面命名的选择原则、当前采用和保留候选统一见 `knowledge/cultural-content-preferences.md`。
- 桌面导航：固定宽度 176px，使用半透明雾白、模糊和低对比边界形成毛玻璃质感；当前一级入口只通过浅色底、细指示条及模块强调色识别。
- 移动导航：四个一级入口在 920px 以下转为带安全区的浅色玻璃底栏；不得使用深色整栏，也不得遮挡页面、弹窗或批注面板。
- 模块色：今日青灰、捕念绿、日记陶土、思绪灰蓝、回顾冷青、读书橄榄、小物灰棕、善言赭金、设置石墨。模块色用于当前项、焦点、少量结构线，不大面积染色正文容器。
- 排版与密度：标题字距固定为 0；操作型界面保持紧凑，不使用营销式大卡片和过度留白。控件、时间线和固定格式元素须有稳定尺寸，桌面与移动端均不得产生横向溢出。

## 前端更新原则

首次启动可全量加载。写操作完成后重新获取状态，但只渲染受影响的数据域，不重绘整个页面：

- `thoughts`：只在思绪主体发生变化时刷新列表与标签，并保存根卡片和追问的展开状态。
- `captures`：只刷新捕念列表；正在编辑的捕念表单不得因其他数据域变化而清空。
- `journals`：只刷新日记列表并保留已展开日记；原文编辑表单和助手回望是两条独立操作。
- 评论与划线：选中文本后可创建需要文字内容的浅黄色评论，或无需填写内容的浅绿色划线。新增、回复和删除直接修补内存记录、对应锚点和右侧面板；不得调用 `refreshState("thoughts")`，也不得替换思绪卡片 DOM。
- 批注锚定：创建时同时保存选中文本、前后短上下文、原始位置和最多前后 1000 字原始上下文。编辑正文时先用“精确文本 + 邻近上下文 + 原位置距离”重定位；找到则平移，找不到则从有效批注移入根记录的 `annotationDrift`，完整保留评论、回复、神鸡对话与原始上下文。漂流项由用户显式删除。
- Markdown 正文统一使用“渲染后可见纯文本”作为批注坐标系；创建校验和编辑重定位都必须先去除 Markdown 结构标记，不得用源码字符位置直接匹配页面选区。
- 所有模型最终输出和声明支持 Markdown 的用户内容统一使用 `renderMarkdown` 后再执行 `renderLatex`，包括思考问题与初步想法、回答、追问问答、长期对话双方消息、神鸡问答、认知复盘、日记与回望、保存后的模型思考、捕念、书目简介和读书笔记。折叠摘要使用 `plainPreview`；编辑框保留源码；评论元数据、标签、来源和引用原文保持纯文本。
- `@神鸡`：评论和划线均可发起批注级 AI 对话，问答保存在对应 annotation 的 `shenji` 数组；返回后只更新当前侧栏卡片。上下文与人格规则见 `knowledge/prompt-architecture.md`。
- `checkins`：保存后刷新状态图、滑块参考和回顾洞察；回顾页的单次状态记录可编辑发生时间、量表、备注和因素，更新不得改写 `createdAt`。
- `dailyRecords`：只刷新每日记录的当前类型历史与可视化；不得重绘“此刻”滑杆或清空其他表单。
- `chat`、`review`、`books`、`keepsakes`、`quotes`：各自独立刷新。

输入框、当前视图、滚动位置和无关区域不应因一次保存而重置。
思考引子异步返回前核对输入、表单重置、日期和当前账户；期间发生变化就保留用户当前输入。小物上传、编辑加载及分割图片解码使用请求序号校验，关闭或切换对象后，旧结果不得覆盖新画布。
账户切换时先锁定并清空旧账户的页面状态、表单、弹窗和媒体引用，只有新账户的 `/api/state` 与设置都成功渲染后才解除遮罩。退出动作先在本地锁屏，再请求服务端注销；旧会话中的在途前端请求随会话控制器中止。
API 公共入口在收到响应头、解码 JSON/图片和消费流式事件后均校验会话代次，即使底层传输未及时中止也拒绝旧响应。多个数据域的并发刷新只接收最新响应，同时合并所有待渲染数据域；原页面通过订阅执行局部渲染。

业务事务在 `_persistence.sync` 中追加账户隔离的单调变更游标，事件只保存
领域、资源 ID、操作 ID、版本、变更类型和提交时间，不复制用户正文。
当前 `/api/v1/sync` 的兼容实现仍可能按受影响领域返回快照，游标过期也可能回退
到完整账户快照；这属于待迁移现状，不是目标契约。新的同步切片必须按
[`design-contracts.md`](../design-contracts.md) 返回记录级变化、版本、必要摘要和
恢复信息，客户端按 ID/版本合并；任务、通知、聚类、统计不得因域名分类而附带
完整集合。推送消息不是权威数据，客户端仍按 cursor 去重并与 IndexedDB 中的
pending overlay 对账；恢复只重取当前分页或指定详情。
`INCREMENTAL_SYNC_ENABLED=0` 只关闭浏览器游标拉取和跨标签收敛，作为灰度回退
到既有写后刷新；它不关闭 durable-first 写队列、幂等键或服务端
`_persistence.sync` 事务账本，因此重新开启后可从服务端游标继续收敛。
可重试写错误采用 1 秒起步、60 秒封顶的指数退避，最多自动发送 8 次；
`429` 优先尊重 `Retry-After`。冲突与失败终态在“我的 / 同步状态”显式展示，
不能在 pending 清空后误报为已对齐。客户端诊断保留最近 200 条成功和 50 条
冲突/失败记录，详细指标口径见 `knowledge/metrics.md`。

图片输入共用格式校验、文件选择、剪贴板、拖放、预览、Data URL 转换与附件落盘。配置火山视觉后，书目和健康截图先走通用 OCR，再由 DeepSeek 按场景提取结构化字段；未配置时保留现有 DeepSeek 图像识别路径。智能文档解析使用独立 `OCRPdf v3` 入口；小物主体分割仍走阿里云接口。书目录入包含两个独立图片槽位：封面图只用于书架展示并在保存时上传，信息识别图只回填可编辑元数据，不能自动成为封面；已有书目的元数据和封面可继续编辑。书目识别、心率和用户选择的原图仅接受 PNG、JPEG、WebP，单张限制 8 MB，一次选择合计限制 48 MB；该批次阈值面向最多 8 张常规手机图片，不承诺专业相机原片。睡眠接收 1～2 张并合并解析，体重和小物批次逐张处理及上传，不把 48 MB 合并成单个请求。小物透明轮廓由浏览器生成 PNG，可能大于原始 JPEG，持久上传接口单张允许 24 MB、请求体允许 36 MB，其他 JSON API 仍限制 12 MB。健康截图只回填可编辑表单，用户确认后才写入记录；截图缺少年份时，以用户当前所选日期推断最近年份，并在核验说明中显式标注。
捕念、思绪根、评论、思绪内容块和健康截图的未提交图片均写入账户隔离的
IndexedDB；弹窗草稿同时保存根记录、子目标、原文定位和稳定请求 ID，恢复时
重新校验目标，不把旧图片附到其他内容。评论和新增思绪内容块在服务端按稳定
请求 ID 原子去重。健康截图先经 `/api/images/upload` 幂等落盘，再把当前账户
附件路径交给识别；替换、移除、确定失败或保存完成后调用 discard，服务端在
附件已被业务记录引用时拒绝误删。页面异常退出时草稿与清理凭据保留，重新
进入同一账户后继续识别、提交或清理。

语音原件仍由账户隔离附件存储持有。捕念保存后，支持的 M4A、Ogg、WAV
原件进入持久后台任务，由服务端读取后通过火山流式 ASR 发送，不生成公共
下载地址；WebM 原件保留但在具备受控转码前不伪装成其他格式。任务先保存
ASR 原文，再独立尝试 DeepSeek 整理稿，整理失败不回滚原文。朗读使用火山
TTS 服务端代理，浏览器只接收 `private, no-store` 的 MP3，不接触 API Key。

书目保存独立的 `readingStartedOn` 与 `readingFinishedOn` 自然日字段：开始日期为新建必填项，结束日期允许为空且不得早于开始日期；旧书目兼容为空，不因增加字段升级存储版本。书籍详情页以笔记为主：轻微滚动后页面标题收拢至左上，随机精选笔记进入左侧，封面、标题、作者、简介及阅读日期缩为右侧摘要；该状态在当前书内保持稳定，返回书架后恢复展开标题。阅读时间线先于新增记录表单展示。

小物收集在 `keepsakes` 中同时保存原图路径 `originalPath`、透明轮廓图路径
`cutoutPath` 和标签 `tags`；历史“类型”字段不再使用。自动分割唯一调用
阿里云 `SegmentHDCommonImage`：服务端以 ECS RAM 角色提交本地图片流，把
异步响应的 `requestId` 作为 `jobId`，通过 VIAPI `GetAsyncJobResult` 取得
结果地址后及时下载临时透明 PNG，再向浏览器返回 Data URL；不调用 DeepSeek
锚点或 `RefineMask`。浏览器只从透明图读取 Alpha 蒙版，按 `edgeExpansion`
做小幅膨胀，随后允许用保留/擦除画笔修正；名称和描述可由用户填写，也可由
DeepSeek 图片理解提供可编辑建议，标签只从用户已有标签中推荐不超过 3 个且
不强行匹配。透明 PNG 始终由原图与蒙版在独立画布生成，陈列与详情则把 15%
不透明度的原图放在底层、100% 不透明度的透明主体放在上层，不能把展示合成图
覆盖为 `cutoutPath`。画廊使用按行优先的 CSS Grid，卡片进入页内详情后可在
默认呈现与完整原图之间切换。服务端不常驻图像分割模型。
历史 `legacy` 小物不会在应用启动时隐式改写。维护人员须先执行只读
`migrate:keepsake-media -- --dry-run`，核对阻断项和计划哈希，再停服并以同一
哈希执行 `--apply`。应用阶段只新增四类派生图并保留旧 `cutoutPath` 和实物，
最终清理须经过备份、恢复演练、观察期和单独授权。

异步 DOM 事件在第一个 `await` 前保存表单、按钮等节点引用，不得在异步恢复后继续读取可能已被清空的 `event.currentTarget`。时间线按 `occurredAt` 排序、按派生的 `occurredOn` 分组：同一日期只在组首显示一次左侧日期。善言的来源及思绪的标签放在内容卡片外上方左侧，时间和该层级的轻量操作放在同一行右侧；元信息不得占用正文卡片空间。编辑发生时间不得改写 `createdAt`。
