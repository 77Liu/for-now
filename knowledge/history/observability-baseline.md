# 历史日志能力与迁移说明

2026-10-17 从日志正文迁出。以下状态、部署与验证均是原记录时点，不作为当前候选或生产结果。

## 当前结论

| 类别 | 当前状态 | 问题追溯能力 |
| --- | --- | --- |
| 系统日志 | 已建立 v1 | API 完成、异常、持久化失败、AI 与外部依赖、后台任务均写入结构化事件，可按请求关联 |
| 用户操作日志 | 已建立 v1 | 关键写请求及 store、settings、auth 的资源变化记录操作者、结果与字段摘要 |
| AI 用量账本 | 已建立 v5 | 可按账户统计每次实际请求、失败、重试、图片输入、Token、非 Token 单位、费用和耗时 |
| AI 调用审计 | 已建立 v1 | 可用 `traceId / callGroupId / callId` 还原一次业务请求中的每次模型尝试，并查看实际 SP、UP、历史、参数、响应和错误 |

以上能力已随生产技术基线 `908004b50d3f` 部署并验证。常规请求可跨系统日志、操作审计与 AI 调用追踪；最低运行告警已完成飞书真实投递，但尚不具备事务级审计保证或集中式指标平台。

工作区 S3 已把异步上下文、日志队列、脱敏、保留期和提交后摘要收拢至 `shared/observability`；HTTP 追踪与请求完成归 `http/request`，配置在启动时由 `config` 注入。根目录旧日志入口已删除，日志格式、目录、权限和费用口径保持兼容。`runtime-infrastructure-regression` 验证并发账户/后台任务归属与 SSE、断连记录；`observability-regression` 另验证日志写入故障期间业务仍提交、故障解除后恢复审计。该重构尚未部署。

AI 设置、用量归一化、单价快照、额度预留与审计记录已迁入 `src/modules/ai`。账户文件/数据库适配在 `shared/persistence`，日志目录由装配注入；私有正文裁剪、开始/终态与图片摘要规则不下沉到通用日志。`ai-domain-regression` 覆盖用量和审计独立失败，HTTP 专项进一步在模型收到请求后阻断账本写入、以及在调用前阻断日志目录，核对成功回答仍返回且供应商只调用一次。原有非事务审计边界仍保留。

DeepSeek 传输现由 `infrastructure/ai-providers` 返回标准结果或携带私有诊断的错误，AI 领域统一记录每次尝试。SSE 逐字节拆包、断流/过滤/截断保留部分输出于私有审计，空正文降级只重试一次且重新检查额度；统计继续读取固化费用。`ai-provider-regression` 覆盖这些边界以及图片摘要和并发账户，供应商适配器不自行重试或写日志。
