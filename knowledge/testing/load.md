# 容量与性能测试入口

返回[系统测试地图](../system-testing.md)。容量或性能是当前验收目标时执行适用测试；普通功能切片不默认运行完整压测。

`npm run test:load` 运行隔离应用和模拟供应商的并发读、写、混合流量及后台任务，检查错误、重复/丢失、持久化和延迟。具体负载、并发、阈值和环境变量以 [load-regression.mjs](../../scripts/load-regression.mjs) 为准，不在文档复制数值。

设置 `LOAD_REPORT_PATH` 保存本次结果。对比记录候选、环境、数据规模、负载、P75/P95 等适用延迟、SQL/往返、读写范围及资源，不能把本机替身结果当生产容量结论。不得为通过而无依据调宽阈值。

生产业务不接受本地压测流量。容量放量和扩容依据见[运维容量](../operations-capacity.md)，日常业务的访问与性能约束见[设计契约](../design-contracts.md)。
