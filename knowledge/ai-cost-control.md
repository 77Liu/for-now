# 个人 AI 成本计算与控制

本文档是“我的 → AI 成本”页面的计算口径和配置建议边界。

## 页面目标

该页面只模拟个人账户的 AI 资源费用，用于回答三个问题：

1. 当前各场景每月大约花多少钱。
2. 成本主要由模型、调用次数、输入上下文还是输出长度驱动。
3. 在不直接修改线上模型配置的前提下，哪种调整最值得先验证。

模拟参数保存在当前账户独立的 `ai-cost-plan.json`，不写入主业务 `store.json`，也不会自动修改 `llm-settings.json`。

工作区实现由 `src/modules/ai` 拥有成本归一化和账本统计，`http/ai-costs` 适配 GET/PATCH，`shared/persistence` 保存账户文档；PostgreSQL 模式使用独立 `costPlan` 文档映射。PATCH 继续整份替换方案，缺省字段由当前设置和近 30 天账本生成；模拟保存失败保留上一份方案。该模块化调整尚未部署。

## 场景变量

15 个 DeepSeek 场景分别维护：

- 是否计入模拟。
- 模拟模型：DeepSeek Flash 或 DeepSeek Pro。
- 计价时段：高峰或空闲时段，按 DeepSeek 中国区官方规则计算。
- 每月调用次数。
- 单次平均输入 Token。
- 输入 Token 缓存命中率。
- 单次平均推理 Token。
- 单次平均回答 Token。

页面同时显示当前真实模型档位，模拟模型与真实配置并列但互不覆盖。
捕念语音整理作为独立 `capturePolish` 场景归因。火山 TTS、ASR、OCR 和文档
解析已进入统一调用账本、每日调用次数门限、供应商/输入方式/场景统计及
PostgreSQL 监控读取。V0.5.8 工作区已把 TTS 字符、流式 ASR 音频毫秒、OCR
调用、文档实际页数和阿里云分割提交映射到官方目录价；分割结果轮询与下载
明确为同一业务调用的零价内部步骤。成功调用会固化人民币估算金额和价格来源，
并进入人民币预算；失败调用若没有供应商计费证据、以及未映射的新动作，保持
“费用待账单”，避免把预留上限误记成实际消费。

统计页按 DeepSeek 文本、DeepSeek 图片理解、豆包语音合成、豆包语音识别、
火山文字识别、火山文档解析和阿里云图片分割七类展示。该口径不包含 OSS/CDN、
资源包摊销或合同折扣，因此仍不能解释为最终供应商账单。

## 计算公式

```text
缓存命中 Token = 平均输入 Token × 缓存命中率
缓存未命中 Token = 平均输入 Token - 缓存命中 Token

单次输入成本 =
  (缓存命中 Token × 命中单价
  + 缓存未命中 Token × 未命中单价)
  ÷ 1,000,000

单次输出成本 =
  (平均推理 Token + 平均回答 Token)
  × 输出单价
  ÷ 1,000,000

场景月成本 = (单次输入成本 + 单次输出成本) × 月调用次数
基础月成本 = Σ 场景月成本
预计月成本 = 基础月成本 × (1 + 不确定性预留)
预计年成本 = 预计月成本 × 12
```

推理 Token 与回答 Token 都按供应商输出 Token 单价计算。模型价格使用统计页
中的同一份 DeepSeek 中国区人民币官方价格快照。人民币/美元换算值仅用于展示
2026-10-02 前已经固化为美元的历史账本，不参与新调用或新模拟方案计价。

## 实测校准

“按实测校准”读取当前账户近 30 天 AI 账本：

- 有调用的场景回填实际调用次数、平均输入、缓存命中率、平均推理和平均回答 Token。
- 模拟模型同步为当前场景实际配置。
- 没有调用的场景暂时关闭并将调用次数设为 0。
- 火山等非 Token 调用只进入实测调用与已知费用汇总，不进入 DeepSeek Token
  参数校准；费用未知调用单列提示。
- 校准只改变页面中的模拟方案，用户保存后才持久化。

单用户短窗口数据只能用于个人预算，不代表整体用户分布。

## 配置建议边界

建议按以下顺序生成：

1. 先检查预计月成本是否超过预算。
2. 找出月成本最高的场景。
3. 对非关键判断场景估算从 Pro 切换 Flash 的节省额。
4. 输入超过 20,000 Token 时，优先建议限制上下文，而不是直接降低模型。
5. 长输入且缓存命中率低于 20% 时，建议稳定系统提示词前缀。

思考回答、追问回答、日记回望和认知复盘默认视为质量敏感场景，不自动建议降级。任何建议都需要通过质量回归后再到“模型设置”中人工应用。

## 运行时费用门限

`AI_USER_DAILY_COST_LIMIT_CNY` 控制兼容账户账本的每日费用预检：

- 正数表示达到该人民币估算费用后拒绝新的 AI 调用。
- `0` 只关闭兼容账本的重复费用预检；站点任务预算仍按 Owner 已确认的单用户
  每日 ¥14.4 / 200 次执行，不能借此绕过全站护栏。
- 未配置时默认值为 `14.4`；旧版
  `AI_USER_DAILY_COST_LIMIT_USD` 只保留兼容读取。

`AI_USER_DAILY_CALL_LIMIT` 已覆盖 DeepSeek、火山 TTS、ASR、OCR、文档解析
与阿里云图片分割。调用会记录服务、动作、计费单位、数量、状态和供应商请求
ID。运行时以版本化官方目录价做预算预留和实际结算；目录价不替代账户合同价，
未映射动作继续标为“费用未知”。OCR + DeepSeek、ASR + DeepSeek 等复合链路
在供应商 I/O 前一次性预留，文档解析先按最多 16 页预留，再按实际返回页数
结算。流式 ASR 不信任客户端上报时长：预算先按 10 分钟上传上限预留，成功后
只按供应商逐句结果中的结束时间结算；缺少该证据时保留账单缺口。
主机监控在 JSON 和 PostgreSQL 两种模式下都会汇总已知人民币费用；PostgreSQL
使用 `PG_BACKUP_DATABASE_URL` 只读角色。费用未知调用只报告覆盖缺口，不
伪造金额，也不触发基于金额的拒绝。

Owner 已确认单用户每日 ¥14.4 / 200 次、全站每日 ¥100、全站每月 ¥2,000，
以及未知费用服务全站每日 10 次。`server.mjs` 已装配根级预算仓储、领域服务与
任务协调器：DeepSeek 在首次调用前一次预留全部可能重试；健康/书籍识别按
“每张 OCR + DeepSeek”整体预留；捕念转写按“ASR + DeepSeek 润色”整体预留。
TTS 只在缓存未命中时预留，阿里分割只把真实提交计为预算阶段，轮询、结果下载
和测试模拟不会重复消耗站点预算。

预算持久化底座已独立闭合：JSON 使用跨进程排他锁并处理崩溃残留和等待超时；
PostgreSQL 使用 `AI_BUDGET_DATABASE_URL` 对应的独立最小权限角色，普通
data/auth 角色不能直接 SELECT/UPDATE `site_ai_budget`。完整迁移、源漂移
校验、关系导出 manifest 和新库恢复均包含根 `ai-budget.json`，并与账户及
认证数据同事务提交。应用启动时会释放完全未启动的残留预留，并对已有阶段启动
的中断任务按预估费用保守结算；恢复失败保留预留并写入错误事件，禁止错误释放。

预算领域服务的预留固定绑定创建时的 UTC 日/月。阶段启动前按注入时钟重新
核对 UTC 周期：完全未启动的过期预留会在同一原子更新中释放并返回
`AI_BUDGET_RESERVATION_EXPIRED`；已有阶段启动时，剩余阶段不得跨周期启动，
任务必须结算，且跨周期结算只接受原周期已持久化 `startedAt` 的阶段，不能用
结算参数事后补写启动状态。已启动费用仍记入原预留周期。真实调用链回归覆盖
预算拒绝发生在供应商 I/O 之前、缓存命中不预留、复合任务原子预留和实际费用
结算。

Owner 通过 `GET/PATCH /api/v1/owner/ai-budget` 查看安全聚合状态、临时追加
日/月额度或解除当前周期阻断。写操作必须携带 ETag 对应的 `If-Match`，actor
只能从服务端会话注入；普通 reserve/start/settle 不改变 Owner 控制版本。

## 官方价格更新

- `npm run test:pricing` 使用离线夹具验证所有解析器与快照结构，不依赖网络。
- `npm run pricing:update` 获取公开官方页面；全部来源都成功解析后才原子替换
  `src/modules/ai/provider-pricing.mjs`。
- 任一页面被 WAF 拦截、字段缺失或单位变化时，命令失败且不覆盖现有快照。
- 火山文档被 WAF 拦截时，可从浏览器导出六个官方页面正文到受审计目录，按
  `deepseek`、`volcengineSpeech`、`volcengineOcr`、
  `volcengineDocument`、`aliyunSegmentation`、`aliyunOss` 命名为
  `.html`、`.md` 或 `.txt`，再运行
  `npm run pricing:update -- --source-dir <目录>`。仍须六项全部通过才写入。
- 火山费用中心的询价 API 需要鉴权及准确商品/计费项代码；在这些代码完成
  人工核对前，更新器不携带生产凭据猜测商品。
- OSS 公开目录价和官网折扣价只用于容量成本参考；最终成本仍以账户资源包、
  请求、流量、合同和账单为准。

## 内部预算与资金预算的分工

内部摘要和上下文使用分层 WARN／二级限额，唯一默认值与环境配置键见
[src/shared/ai-context/internal-budgets.mts](../src/shared/ai-context/internal-budgets.mts)，部署模板仅列配置入口。
摘要初级超限的合法结果保留并标记 WARN；超过二级、JSON 不完整或来源无效时拒绝保存，
不靠裁掉合法正文制造成功。程序统计完整保存并单独计量，不占模型摘要额度。
稳定表达候选维持独立预算，不与日摘要混用。

趋势块只包含摘要、统计和缺口。引用原文进入独立证据层，提供有界连续片段，并记录
摘录缺口。最终请求按 UTF-8 字节限制；内部 token 是统一保守估算，不是供应商 usage。
实际短请求的哈希、字节数、目录映射摘要和提供数量进入调用及保存回执。
来源必须同时匹配真实原文与本次发送的连续片段；分离的片段不得拼接成逐字证据。
参考目录说明哪些来源确实发送，实际引用另经服务端核验，不证明模型内部因果依赖。

上述 WARN 不放宽任何账户、站点资金或调用限额。真实调用仍按实际请求和供应商输出
上界保守预留，并按既有账本结算。内部错误可用率目标需明确账户操作的分母、统计窗口
及应用／供应商归因，使用真实故障回执；局部合成专项通过不能宣称长期可用率已达标。
