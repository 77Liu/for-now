## 本轮明确不做

- 不把 AI 回答当作用户意见。
- 不为了“高并发”提前拆微服务、上 Kubernetes、Kafka 或独立向量数据库。
- 不默认采集精确位置或后台路线。
- 不把样例、社区内容或开发者数据混入用户画像和统计。
- 不在没有迁移校验、恢复路径和兼容方案时替换 JSON 数据源。
