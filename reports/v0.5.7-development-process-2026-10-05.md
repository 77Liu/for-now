## 2. 目标与实际结果

原目标是让已登录用户只为当前页面付出启动、数据和媒体成本，并在手机端完成
思绪、念起和标签等高频操作。

实际结果：

- 启动改用有界 `startup` 与当前路由投影，不再请求完整 `/api/state`。
- 隐藏路由不挂载媒体 DOM；小物列表只使用派生图；附件支持本地和 OSS Range。
- 思绪列表、详情、整链朗读、念起独立录入、善言多标签和移动端操作已上线。
- 历史小物生产迁移 9/9 成功，迁移后备份和隔离恢复通过。
- 初始生产走查发现音频仍会因 `preload="metadata"` 提前下载；经独立热修后，
  Preview 与生产均实现播放前 0 请求、点击后 `206`。
- 热修后 30 分 04 秒观察无重启、5xx、应用 warning/error 或 OOM。

未覆盖物理 iPhone、安装态 PWA 和 Android 真机。本版网页生产关闭不代表这些
物理设备已经通过。

## 7. 复盘结论与行动项

### 有效做法

- 路由投影、媒体 Range 和 UI 切片在独立所有权下开发，公共入口由单一集成线
  串行接入，避免共享热点并发冲突。
- 固定 Fast 4G、真实 HTTP、Preview Linux 长稳和生产登录态走查提供了不同
  层级的反证，最终发现了合成首屏样本未覆盖的音频问题。
- 热修只改变播放器预载语义和对应回归，没有改媒体 URL、Range 或持久化数据。

### 行动 R57-01：媒体性能门必须含真实持久媒体路由

| 字段 | 内容 |
| --- | --- |
| 现象 | 原性能门宣称点击前媒体 0 B，但其首页夹具没有挂载历史录音 |
| 原因 | 测试样本与受影响路由不一致，UI 测试只检查元素存在 |
| 行动 | 每种可持久媒体至少选一条真实挂载路由，用 CDP 断言用户触发前正文 0 请求 |
| 负责人 | Agent |
| 优先级 | P00 |
| 验收 | 原始录音与持久 TTS 在播放前 0 请求，点击后为合法 `206` |
| 回流 | `scripts/ui-regression.mjs` 与 `one-mistake-one-rule.md` |

该行动已经由 `7ed6286` 完成并进入热修发布。
