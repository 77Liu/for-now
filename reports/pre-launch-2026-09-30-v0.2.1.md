  SHA-256，不输出正文、路径内容或凭据。

### Bug 修复

#### 小物恢复摘要误报｜Bug 修复

**Bug 描述：** 完整备份中的小物数量、ID 和附件均一致时，恢复演练仍会在
API 内容摘要检查处误报失败。

**原因：** 验证器直接比较包含私有原图路径的备份对象与隐藏该路径、补齐
兼容字段的公开 API 对象，两个视图的哈希口径不一致。

**解决方案：** API 期望摘要改用与线上接口相同的 `publicKeepsake` 投影，
同时继续对原始备份和附件实物执行完整校验，并在失败时输出无正文的集合级
差异证据。
