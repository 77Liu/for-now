- 视口：桌面、390px 移动端、320px 窄屏。
- 判定规则：仅记录可复现的错误行为或违反既定 44px 移动触控门槛的问题。
  浏览器代理异常视口、自动化工具不支持文件上传等不计为产品 Bug。

## 12 个确认 Bug

| ID | 等级 | 复现结果 | 修复 |
| --- | --- | --- | --- |
| B01 | P0 | 增量同步定时器始终请求 `waitMs=0`，前台空闲标签页约每分钟产生 40 次空拉取 | 定时拉取改用 `waitMs=1500` 长轮询 |
| B02 | P0 | 寻迹“明天再看”请求失败时无任何界面反馈 | 显示明确错误 toast，并恢复按钮 |

| B04 | P1 | 设置页“思考草稿/回答/回望”等多组下拉框读屏名称重复，无法区分回答风格、思考强度与场景档位 | 为每个下拉框增加唯一语义名称 |
| B05 | P1 | 捕念页标签输入与提交操作低于 44px | 移动端基础输入和按钮统一 44px |
| B06 | P1 | 书间创建与图片交换操作低于 44px | 同上，并保证图标按钮宽高均为 44px |
| B07 | P1 | 拾句刷新、输入与收藏操作低于 44px | 同上 |
| B08 | P1 | 思绪筛选按钮低于 44px | 同上 |
| B09 | P1 | 统计页周期按钮为 30px，日期与统计操作为 38px | 同上 |
| B10 | P1 | 设置页恢复默认按钮为 28px，多数组合框为 38px | 同上 |
| B11 | P1 | 账户页输入与修改按钮为 42px，退出登录仅 28px | 同上 |
| B12 | P1 | 产品反馈页输入与提交操作为 40–42px | 同上，并扩展复选项标签点击区域 |

同一移动端基础规则还覆盖了首页行动/习惯、每日、日记、回顾、个人概要、
回收站和导出页中扫描到的同类遗漏，避免逐页补丁继续漏项。

## 验证

- 新增同步回归：定时轮询必须携带正数 `waitMs`。
- 新增寻迹回归：已读失败仍打开原记录；稍后再看失败必须可见。
- 新增移动端回归：代表性导航与操作目标至少 `44 × 44 CSS px`。
- 本地真实浏览器逐页扫描 320px：目标页面无横向溢出，非原生复选/滑杆类
  可见按钮、文本输入与下拉框均无低于 44px 的目标。
- 设置页无障碍树可区分“回答风格”“思考强度”“场景档位”。
