## G2 权限与导航

1. 当前仅保留 `user` 与 `owner` 两类角色，不建设更细的用户分层。
2. 主账户获得 Owner；新注册账户默认是普通用户。
3. AI 成本、架构、商业化、本地测试、供应商、模型与 API 密钥均仅 Owner 可见。
4. 普通用户不配置 API 密钥，但可以按场景调整 DeepSeek 推理强度。
5. 撤销 Owner 权限后立即使既有会话失效，并提示重新登录。
6. 未授权访问 Owner 页面时显示权限页，不返回敏感页面内容。
7. 四个一级入口保持不变；“我的”只承载普通账户设置，个人概要只保留一个主操作。
8. 服务端 capability 是发布阻断项。前端隐藏只能改善体验，不能作为授权边界。
9. 当前权限系统不是产品着力点；实现以最小角色模型、清晰服务端校验和可审计撤权为准。

## URL 与历史记录

以下项目由 Owner 暂时采用工程建议，后续可在路由契约评审中修改：

- 页面使用可分享的 canonical path；详情页使用 path，筛选、排序和分页使用 query。
- 页面切换与详情进入使用 `pushState`；同页筛选使用 `replaceState`。
- 浏览器前进/后退恢复页面、筛选条件和滚动位置。
- `/now/` 兼容跳转至“今日”。
- API 使用可理解、带分隔的 RESTful 路径。
- 已删除对象的旧 URL 返回安全列表，并用结构稳定的结果说明对象已不可用。
- URL 迁移须提供旧路径兼容和直接打开回归，不接受只在单次 SPA 会话内可用。
