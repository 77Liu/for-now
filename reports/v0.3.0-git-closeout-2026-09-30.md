## 恢复方法

查看某份归档：

```bash
git show --stat archive/v0.2.0-r3-a-20260930
git diff main archive/v0.2.0-r3-a-20260930 -- path/to/file
```

需要恢复单个文件时，先在新的临时任务分支中逐文件比较，不得把整个归档分支
合并进 `main`。任何归档分支删除、原 stash 删除或远端推送仍需单独确认。
