## 3. 实际交付

### 3.1 性能

- 核心 state/meta 返回后立即显示当前路由，设置、onboarding、草稿、同步和
  行动水合移到首帧后。
- 新增最小 bootstrap：同步入口 6 个模块 / 27,779B；完整 runtime 动态加载，
  auth/state/meta 各请求一次。
- 阻塞样式由 4 个 / 269,370B 降为 2 个 / 245,319B。
- KaTeX 只在出现公式时加载；并发复用、失败可重试，PWA 仍保留离线闭包。
- 两张背景保留 PNG 原图，并增加媒体选择的 AVIF/WebP：
  桌面 AVIF 13,197B、移动 AVIF 8,155B。
- 部署阶段为公开文本生成 `.gz`，Nginx 使用 `gzip_static`；HTML 低级别压缩
  且保持 `no-store`，API 和私人附件不进入静态缓存路径。

性能门最终复验：

| 环境 | DCL | 当前屏反馈 | stableHome | 资源 / 传输 |
| --- | ---: | ---: | ---: | ---: |
| 本地冷缓存 | 90.6ms | 93.6ms | 180.0ms | 37 / 288,167B |
| Fast 4G（10Mbps/40ms） | 176.1ms | 273.0ms | 672.8ms | 37 / 288,167B |

真机/WKWebView 和生产 TLS 未测试，不以浏览器仿真代替。

### 3.2 正确性与交互

- 五问提取按 `kind + targetId + inputHash` 复用 queued/running/succeeded
  任务；同输入只调用、落 claims 和结算一次。
- 追问新增、手写回答和编辑成功后精确消费双页面草稿并关闭表单；失败和轮询
  保留输入；新增追问增加幂等键。
- 390px 追问按钮增加底部滚动安全区，展开后保证提交按钮完整位于固定导航
  上方。
- 旧同步队列在恢复前重算 operation fingerprint；失败分为 format、
  missing-id、canonical-mismatch，最多重试一次且复用原幂等键。
- 冷启动 bootstrap 的 local-test-mode 结果传给 runtime，不再重复请求。

### 3.3 音频与可访问性

- TTS 使用卡片内真实 audio source；自动播放被拒后仍保留供手动播放。
- 空播放器隐藏；卡片仅保留生成/重新生成和播放倍速，音色集中到设置页。
- 无效或历史坏音色按服务白名单回退，不再阻断账户全部朗读。
- 320/390px 组内导航至少 44×44；语速滑杆提供“默认生成语速”和
  `0.90倍` 等 `aria-valuetext`。

### 3.4 运维可靠性

- 备份成功标记严格晚于服务 ready、两次 OSS 上传和本地清理；失败 trap
  保留原退出码并尝试恢复服务。
- 每分钟记录低敏 RSS、heap、external、arrayBuffers、V8 heap spaces、
  事件循环延迟和活动句柄类别。
- 运行时 RSS 使用 400/360 MiB 告警/恢复回滞。
- 六阶段 memory soak 覆盖冷启、state、管理快照、analyses、Sharp 和空闲
  回收。默认本地峰值 190.8 MiB、空闲后 125.0 MiB；短窗不证明平台期。
- Fontconfig 使用 `${DATA_DIR}/cache/fontconfig` 私有 0700 目录并拒绝
  符号链接；macOS 测试自动使用临时 ad-hoc Node。
