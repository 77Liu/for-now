版本定位：把记录、媒体、同步与个人语境从单机交互升级为可恢复、可追溯、

### 新功能

- 新增可恢复语音捕念：支持音频上传、现场录音暂停/继续、私密音频存储、

## 核心更新

### 1. 可恢复语音捕念｜新功能

**用户故事：** 作为移动场景下不方便打字的用户，我希望上传或现场录制语音，
并在中断后继续处理，以保留当下想法而不依赖一次成功的网络请求。

**更新内容：** 新增音频上传与录音控制、私密幂等上传、豆包流式/文件 ASR、
原文与 AI 整理稿分层、TTS 播放和刷新恢复。

**用户价值：** 捕念不再局限于文字输入，原始音频和机器整理结果保持可区分、
可回看、可恢复。

### 2. 持久写队列与增量同步｜新功能

**用户故事：** 作为会在弱网、刷新或多标签页中持续记录的用户，我希望保存
动作立即可见且最终可靠落库，以减少重复提交和内容丢失。

**更新内容：** 为约定范围内的纯数据写入增加稳定幂等键、持久队列、可逆投影、
退避重试、操作终态、变更游标和跨标签页失效通知。

**用户价值：** 网络波动时记录仍可保留并自动收敛，冲突与失败不再被隐藏。

### 3. 可追溯个人概要｜新功能

**用户故事：** 作为长期记录的用户，我希望知道系统当前如何理解我、依据哪些
原始记录，以便检查模型判断而不是被不可见画像替代。

**更新内容：** 新增只读个人概要、来源版本与时间窗、必要摘录和原记录跳转；
AI 应答记录输入收据，来源变化时拒绝保存陈旧结果。

**用户价值：** 用户可以核对判断出处，删除或修改原记录后，旧结论不会继续被
当作当前事实。

### 4. 批量健康与小物录入｜功能优化

此前体重截图和小物照片需要逐次完成选择、识别与保存，失败后还要重新开始；
本次增加最多 8 张的批次队列、逐项核对、重试、草稿恢复和幂等创建，使连续
整理手机图片时可逐项推进且不会重复写入。

### 5. 鉴权媒体查看｜UX 优化

此前私人图片依赖单独打开，切换、加载失败和键盘退出的反馈不统一；本次将内容
图片和四类健康截图统一到应用内查看器，补齐上一张/下一张、页码、焦点循环、
`Escape` 关闭、错误态与对象 URL 回收。

### 6. 按页面与视口加载｜性能优化

优化模拟模式和媒体读取【性能优化；切换等待与请求数量】：此前切换模式时会在
确认前请求完整数据，并串行补全小物媒体；现改为确认前零业务请求、页面级记录
加载、视口内图片懒加载和去重并行下载。受控 1500 ms/附件场景中，小物补全由
`3013 ms` 降至 `1520 ms`，服务端切换由 `3068 ms` 降至 `1557 ms`。

## Bug 修复

### 1. 模拟模式确认前加载

**Bug 描述：** 用户点击“切换模拟”后，在确认弹窗尚未确认时就开始加载线上
业务数据。

**原因：** 模式切换状态先触发了完整数据 hydrate，确认弹窗没有形成请求边界。

**解决方案：** 将模式切换改为冷启动状态机，确认前保持零业务请求，确认后仅
按进入页面加载所需集合。

### 2. 快照覆盖并发本地写

**Bug 描述：** 页面首次加载期间同时新增记录时，较晚返回的远端快照可能使
刚创建的本地投影短暂消失。

**原因：** hydrate 使用整集合替换，且页面 effect 的恢复顺序早于快照落地。

**解决方案：** 按 ID 合并远端与本地记录，并在页面 effect 完成后统一重放
待确认投影。

### 3. 异步文件选择中断

**Bug 描述：** 部分图片、音频或小物文件选择后，异步处理会因事件对象失效
而中断。

**原因：** 异步回调继续读取已经离开有效生命周期的 `event.currentTarget`。

**解决方案：** 在进入异步边界前固定文件与表单引用，并补齐三类入口回归。

### 4. 图片蒙版比例偏移

**Bug 描述：** 高分辨率原图使用低分辨率预览编辑轮廓时，保存结果可能与
用户画笔位置不一致。

**原因：** 预览坐标没有按原图尺寸等比例映射。

**解决方案：** 保存前按原图与编辑画布比例转换蒙版坐标，并保留原图与派生图
的独立版本。

### 5. 并行 AI 结果误过期

**Bug 描述：** 两个 AI 任务并行时，其中一个结果写回可能使另一个仍基于相同
用户输入的结果被判定过期。

**原因：** 新鲜度只比较全局业务版本，无法区分输入来源变化与 AI 自身写回。

**解决方案：** 改为比较逐来源内容哈希与全局 Prompt 哈希，仅真实输入变化
使结果失效。
