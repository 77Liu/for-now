## 功能优化

- **保存与恢复**：手动补录日期和“现在”模式随账户草稿恢复；用户刷新或切换页面后可以接续输入，旧会话迟到结果不会覆盖新账户状态。
- **保存反馈**：记录已写入后，后续同步或派生失败分别呈现；未知写入结果保留草稿及请求标识，恢复时先核对实际结果，避免重复保存。
- **通知操作**：只对已成功加载并呈现的范围维护已读事实；未加载及新到通知保留未读。复制失败时仍可取得脱敏诊断内容，并保留重试入口。
- **累计稳定性改进**：保留 v0.5.13.1 的账号刷新恢复、小物图片重复渲染缓解与加载改进，以及 AI 提交状态提示和未知区域上下文说明；真实设备性能不附会量化收益。

## Bug 修复

- **思绪回答等待**：没有提交补充问答的用户可能被阻断在“等待核心用户模型”。此前把模型尚未就绪一概视为思绪任务前置条件。现按实际提交事实区分：未提交时允许用缺省模型上下文继续；已提交时等待当前问答整理，保持失败和取消可恢复。
- **失败后重复提交**：保存失败、同步失败和结果未知混在一起时，用户可能重发已完成请求。此前反馈未充分区分持久化与后续处理。现保留请求身份和恢复状态，分别处理已写入、明确失败及未知结果，不靠重复写入恢复。
- **通知未读与诊断恢复**：未呈现通知可能被误当已读，复制失败也容易中断诊断操作。此前读状态和操作恢复未完全沿真实呈现范围维护。现只确认已呈现范围，失败保留脱敏内容与重试，不携带私密正文或凭据。
