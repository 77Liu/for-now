# v0.5.11 · Web

发行日期：2026-10-10（Asia/Shanghai）
相对版本：v0.5.10+hotfix.1

本版重点：新用户可以通过问答建立有来源记录的核心模型；其他个性化回答会等模型就绪后再生成。

## 新增

- **冷启问答与补答**：新用户可回答或跳过初始化问题；已有用户可从明确入口补答。只有有效回答形成核心模型，不会从旧记录静默推断用户答案。
- **回答依据核验**：思绪回答、追问和审记回答可以引用本次上下文确实提供且仍有效的来源；无效、伪造或被撤权的引用会被拒绝。
- **等待模型就绪**：核心模型尚未就绪时，个性化回答任务会保留为待处理意图，模型就绪后再用当时有效的来源和许可生成。

## 改进

- **撤权与账户隔离**：来源许可变化或账户状态变化时，旧模型和等待任务失效，过期的异步结果不会覆盖新状态。
- **回答呈现**：已覆盖场景只显示服务端核验通过的来源引用；普通账户不获得私有核心模型细节。

## 已知限制

- 本地合成回归验证了就绪门禁、任务恢复、账户隔离、撤权失效与引用结构。真实 provider 是否始终遵从引用提示尚未验证，模型自述不能作为真实使用来源的证明。
