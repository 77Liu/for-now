# V0.5.10 最小候选发布记录（2026-10-09）

## 发行说明（Release Note v2；2026-10-09 更新）

# v0.5.10 · Web

发行日期：2026-10-09（Asia/Shanghai）
相对版本：v0.5.9

本版为思绪回答空正文增加有限恢复，并让缺少确认回调的个人概要页面保留安全的只读入口。

## 改进
- **思绪 AI 回答**：DeepSeek 返回空正文时增加最多一次有界降级尝试；仍无内容时保留原思绪并提示失败。此次没有执行真实提供商或生产 AI 旅程验证，上游根因仍未确认。

## 修复
- **个人概要入口**：缺少确认回调时仍可读取页面；需要确认的拒绝/撤回操作默认取消，不发送写请求。

## 已知限制
- 首次 v0.5.10 部署的页面页脚仍显示 v0.5.9。这是该版遗漏同步版本元数据造成的可见问题；修正作为独立 v0.5.10+hotfix.1 版本处理，保留旧标签。
- 未验证真实模型提供商响应和登录用户的生产保存/读取旅程；本版的本地回归与匿名认证边界不能替代这些验证。
